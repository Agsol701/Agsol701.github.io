螺旋矩阵

Apr 07, 2026

题目描述

原题链接：https://leetcode.cn/problems/spiral-matrix-ii/

给你一个正整数 n，生成一个包含 1 到 n^2 所有元素，且元素按顺时针顺序螺旋排列的 n x n 正方形矩阵 matrix。

示例 1：

输入：n = 3 输出：[[1,2,3],[8,9,4],[7,6,5]]

示例 2：

输入：n = 1 输出：[[1]]

提示：

  • 1 <= n <= 20

解题思路

这道题的核心思路是 按层模拟。

可以把整个矩阵看成一圈一圈向内收缩的“环”：

  • 先填充最外层的上边
  • 再填充最外层的右边
  • 再填充最外层的下边
  • 最后填充最外层的左边
  • 然后边界收缩，继续填下一层

因此，我们用四个变量维护当前这一层的边界：

  • left：当前左边界
  • right：当前右边界
  • top：当前上边界
  • bottom：当前下边界

每填完一条边，就把对应边界向中间收缩：

  • 填完上边后，top += 1
  • 填完右边后，right -= 1
  • 填完下边后，bottom -= 1
  • 填完左边后，left += 1

1. 为什么需要 if top <= bottom

这一句出现在“填充下边”之前。

因为我们在填完上边和右边之后，边界已经发生了变化：

  • top 可能已经大于 bottom

这说明当前这一层已经没有剩余的“下边”可填了。

如果不加这个判断，可能会出现：

  • 重复填充同一行
  • 在奇数阶矩阵的最后一层，把中间那一行重复覆盖

比如 n = 1 或者进入最后一圈时只剩一行，填完上边之后，其实这一层就结束了，再去填“下边”就是重复操作。

所以：

  • top <= bottom 说明当前仍然存在一条合法的下边
  • top > bottom 说明下边已经不存在，不能再填

2. 为什么需要 if left <= right

这一句出现在“填充左边”之前。

原因和上面类似：在填完右边、下边之后，边界再次收缩：

  • right 可能已经小于 left

这时说明当前这一层已经没有剩余的“左边”可填了。

如果不加这个判断，可能会出现：

  • 重复填充同一列
  • 在最后只剩一列时，把中间列重复覆盖

所以：

  • left <= right 说明当前仍然存在一条合法的左边
  • left > right 说明左边已经不存在，不能继续填

3. 这两个判断本质上在防什么

本质上，这两个判断是在防止：

  • 边界收缩后已经没有可填区域
  • 但代码仍然继续去填“下边”或“左边”
  • 从而导致重复覆盖元素

也可以理解为：

  • 上、右两条边填完后，矩阵剩余区域可能已经退化成一行、一列，甚至没有区域
  • 这时必须先判断边界是否合法，再决定是否继续填下边和左边

复杂度分析

时间复杂度：O(n^2)

  • 需要把矩阵中的每一个位置都填一次
  • 总共有 n^2 个位置

空间复杂度：O(n^2)

  • 需要额外创建一个 n x n 的结果矩阵

from typing import List


class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        if n <= 0:
            return []

        matrix = [[0] * n for _ in range(n)]

        left, right = 0, n - 1
        top, bottom = 0, n - 1
        num = 1

        while left <= right and top <= bottom:
            for i in range(left, right + 1):
                matrix[top][i] = num
                num += 1
            top += 1

            for i in range(top, bottom + 1):
                matrix[i][right] = num
                num += 1
            right -= 1

            if top <= bottom:
                for i in range(right, left - 1, -1):
                    matrix[bottom][i] = num
                    num += 1
                bottom -= 1

            if left <= right:
                for i in range(bottom, top - 1, -1):
                    matrix[i][left] = num
                    num += 1
                left += 1

        return matrix

func generateMatrix(n int) [][]int {
	if n <= 0 {
		return [][]int{}
	}

	matrix := make([][]int, n)
	for i := 0; i < n; i++ {
		matrix[i] = make([]int, n)
	}

	left, right := 0, n-1
	top, bottom := 0, n-1
	num := 1

	for left <= right && top <= bottom {
		for i := left; i <= right; i++ {
			matrix[top][i] = num
			num++
		}
		top++

		for i := top; i <= bottom; i++ {
			matrix[i][right] = num
			num++
		}
		right--

		if top <= bottom {
			for i := right; i >= left; i-- {
				matrix[bottom][i] = num
				num++
			}
			bottom--
		}

		if left <= right {
			for i := bottom; i >= top; i-- {
				matrix[i][left] = num
				num++
			}
			left++
		}
	}

	return matrix
}
