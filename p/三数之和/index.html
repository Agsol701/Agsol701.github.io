三数之和

Apr 17, 2026

题目描述

原题链接：https://leetcode.cn/problems/3sum/

给你一个整数数组 nums，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k，同时还满足 nums[i] + nums[j] + nums[k] == 0。

请你返回所有和为 0 且不重复的三元组。

注意： 答案中不可以包含重复的三元组。

示例 1：

输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0
不同的三元组是 [-1,0,1] 和 [-1,-1,2]

示例 2：

输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0

示例 3：

1

输入：nums = [0,0,0]
输出：[[0,0,0]]

提示：

  • 3 <= nums.length <= 3000
  • -10^5 <= nums[i] <= 10^5

解题思路

核心目标：找到数组中和为 0 的三元组，且结果不能有重复。

本题的难点不在于找到三元组，而在于去重。

方法一：哈希表（seen 集合）

将问题转化为两数之和：固定一个数 nums[i]，在剩余部分中找两个数之和等于 -nums[i]。

  1. 对数组排序（方便去重）
  2. 遍历数组，固定 nums[i]，若与前一数相同则跳过（去重）
  3. 用 seen 集合记录 nums[i] 之后遍历过的元素，查找 -nums[i] - nums[j] 是否在集合中
  4. 找到后对 nums[j] 也需要去重

时间复杂度：O(n²) 空间复杂度：O(n)，哈希表存储

方法二：哈希表（计数表）

思路更直观：先统计每个数出现几次，两层循环枚举前两个数，直接查表判断第三个数是否存在且次数足够。

  1. 对数组排序（方便去重和剪枝）
  2. 用计数哈希表统计每个数的出现次数
  3. 遍历数组，固定 nums[i]，若与前一数相同则跳过（去重）
  4. 再遍历 nums[i] 之后的元素，固定 nums[j]，若与前一数相同则跳过（去重）
  5. 计算第三个数 c = -nums[i] - nums[j]，查表判断 c 是否存在：
    • 若 c < nums[j]，说明这个组合已经被更小的 j 找过了，跳过
    • 若 c == nums[j]，需要出现至少 2 次
    • 若 c == nums[i] == nums[j]，需要出现至少 3 次
    • 否则出现至少 1 次即可

时间复杂度：O(n²) 空间复杂度：O(n)，哈希表存储

方法三：双指针

排序后使用双指针，去重更简洁：

  1. 对数组排序
  2. 遍历数组，固定 nums[i]：
    • 若 nums[i] > 0，由于数组已排序，后续不可能有和为 0 的三元组，直接终止
    • 若 nums[i] 与前一个相同则跳过（去重）
  3. 在 nums[i] 之后使用左右指针 left 和 right：
    • 若 nums[i] + nums[left] + nums[right] < 0，left 右移
    • 若 nums[i] + nums[left] + nums[right] > 0，right 左移
    • 若等于 0，记录结果，同时跳过 left 和 right 的重复值

时间复杂度：O(n²) 空间复杂度：O(1)，不考虑排序的额外空间

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = []
        for i in range(len(nums)):
            if nums[i] > 0:
                break
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            seen = set()
            for j in range(i + 1, len(nums)):
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue
                complement = -nums[i] - nums[j]
                if complement in seen:
                    res.append([nums[i], nums[j], complement])
                seen.add(nums[j])
        return res

func threeSum(nums []int) [][]int {
	sort.Ints(nums)
	res := [][]int{}
	for i := 0; i < len(nums); i++ {
		if nums[i] > 0 {
			break
		}
		if i > 0 && nums[i] == nums[i-1] {
			continue
		}
		seen := map[int]bool{}
		for j := i + 1; j < len(nums); j++ {
			if j > i+1 && nums[j] == nums[j-1] {
				continue
			}
			complement := -nums[i] - nums[j]
			if seen[complement] {
				res = append(res, []int{nums[i], nums[j], complement})
			}
			seen[nums[j]] = true
		}
	}
	return res
}

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        freq = {}
        for num in nums:
            freq[num] = freq.get(num, 0) + 1

        res = []
        for i in range(len(nums)):
            if nums[i] > 0:
                break
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            for j in range(i + 1, len(nums)):
                if j > i + 1 and nums[j] == nums[j - 1]:
                    continue
                c = -nums[i] - nums[j]
                if c < nums[j]:
                    continue
                if freq.get(c, 0) >= (3 if c == nums[i] == nums[j]
                                      else 2 if c == nums[j]
                                      else 1):
                    res.append([nums[i], nums[j], c])
        return res

func threeSum(nums []int) [][]int {
	sort.Ints(nums)
	freq := map[int]int{}
	for _, num := range nums {
		freq[num]++
	}

	res := [][]int{}
	for i := 0; i < len(nums); i++ {
		if nums[i] > 0 {
			break
		}
		if i > 0 && nums[i] == nums[i-1] {
			continue
		}
		for j := i + 1; j < len(nums); j++ {
			if j > i+1 && nums[j] == nums[j-1] {
				continue
			}
			c := -nums[i] - nums[j]
			if c < nums[j] {
				continue
			}
			need := 1
			if c == nums[j] {
				need = 2
			}
			if c == nums[i] {
				need = 3
			}
			if freq[c] >= need {
				res = append(res, []int{nums[i], nums[j], c})
			}
		}
	}
	return res
}

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = []
        for i in range(len(nums)):
            if nums[i] > 0:
                break
            if i > 0 and nums[i] == nums[i - 1]:
                continue
            left, right = i + 1, len(nums) - 1
            while left < right:
                s = nums[i] + nums[left] + nums[right]
                if s < 0:
                    left += 1
                elif s > 0:
                    right -= 1
                else:
                    res.append([nums[i], nums[left], nums[right]])
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1
                    left += 1
                    right -= 1
        return res

func threeSum(nums []int) [][]int {
	sort.Ints(nums)
	res := [][]int{}
	for i := 0; i < len(nums); i++ {
		if nums[i] > 0 {
			break
		}
		if i > 0 && nums[i] == nums[i-1] {
			continue
		}
		left, right := i+1, len(nums)-1
		for left < right {
			s := nums[i] + nums[left] + nums[right]
			if s < 0 {
				left++
			} else if s > 0 {
				right--
			} else {
				res = append(res, []int{nums[i], nums[left], nums[right]})
				for left < right && nums[left] == nums[left+1] {
					left++
				}
				for left < right && nums[right] == nums[right-1] {
					right--
				}
				left++
				right--
			}
		}
	}
	return res
}

复杂度分析

方法 时间复杂度 空间复杂度
哈希表（seen 集合） O(n²) O(n)
哈希表（计数表） O(n²) O(n)
双指针 O(n²) O(1)

选择建议：

  • seen 集合方法思路与两数之和一脉相承，但 seen.add 的位置容易写错
  • 计数表方法逻辑更直观，“查表看第三个数够不够用"一目了然
  • 双指针方法是本题最优解法，去重逻辑清晰且空间为 O(1)
