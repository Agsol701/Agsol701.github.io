滑动窗口最大值

May 29, 2026

题目描述

原题链接：https://leetcode.cn/problems/sliding-window-maximum/

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。

你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

返回滑动窗口中的最大值。

提示：

  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4
  • 1 <= k <= nums.length

解题思路

这道题要求每个长度为 k 的窗口中的最大值。

如果每次窗口移动后都重新遍历窗口求最大值，单次需要 O(k)，总时间复杂度是 O(nk)，在数据量较大时会超时。

更好的做法有两种：优先队列和单调队列。

为什么需要优化

暴力滑动窗口虽然也是遍历数组，但它的问题在于：每形成一个窗口，都要重新遍历窗口里的 k 个元素来找最大值。

如果数组长度为 n，窗口数量大约是 n - k + 1，每个窗口都要扫描 k 个元素，所以总时间复杂度接近：

1

O((n - k + 1) * k) ≈ O(nk)

当 n 和 k 都很大时，会有大量重复比较。

例如：

1

nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3

暴力法会分别扫描：

1
2
3
4
5
6

[1, 3, -1]
[3, -1, -3]
[-1, -3, 5]
[-3, 5, 3]
[5, 3, 6]
[3, 6, 7]

可以看到，同一个元素会在多个窗口中被重复比较。

单调队列的优化点在于：它不会每次重新扫描整个窗口，而是在遍历数组的过程中维护“还有可能成为最大值的元素”。

如果一个元素右边出现了更大的元素，那么只要这个更大的元素还在窗口中，前面那个更小的元素就不可能再成为最大值，可以直接从队列中移除。

因此，每个元素最多入队一次、出队一次，总时间复杂度是 O(n)。

方法一：优先队列

优先队列也可以解决这道题。

优先队列中保存二元组 (值, 下标)，并且按照值从大到小排序。这样堆顶元素就是当前还未过期元素中的最大值。

因为 Python 的 heapq 默认是小根堆，所以可以把值取负数后放入堆中，用 (-nums[i], i) 来模拟大根堆。

核心规则：

  1. 先把前 k 个元素加入堆中
  2. 堆顶元素就是第一个窗口的最大值
  3. 从第 k 个元素开始遍历，每次把当前元素加入堆
  4. 如果堆顶下标已经不在当前窗口 [i - k + 1, i] 内，就持续弹出堆顶
  5. 弹出过期元素后，堆顶就是当前窗口最大值

为什么只需要检查堆顶是否过期？

因为只有堆顶元素会影响答案。堆中可能存在一些已经离开窗口的旧元素，但只要它们不在堆顶，就不会影响当前最大值；等它们成为堆顶时再弹出即可，这种方式也叫“延迟删除”。

时间复杂度：O(n log n)，每个元素最多入堆、出堆一次
空间复杂度：O(n)，堆中可能保留尚未弹出的过期元素

方法二：单调队列

单调队列中保存数组下标，并且让队列中下标对应的元素值保持从队头到队尾单调递减。这样队头下标对应的元素永远是当前窗口中的最大值。

核心规则：

  1. 遍历数组下标 right
  2. 如果队头下标已经不在当前窗口 [right - k + 1, right] 内，就从队头移除
  3. 插入当前元素前，持续移除队尾中小于等于 nums[right] 的下标
  4. 将当前下标加入队尾
  5. 当窗口长度达到 k 后，队头元素就是当前窗口最大值

为什么要移除队尾更小的元素？

因为当前元素 nums[right] 比它们更大，并且下标更靠右。只要当前元素还在窗口中，这些更小且更早进入窗口的元素就不可能成为最大值。

例如：

1

nums = [1, 3, -1], k = 3

遍历到 3 时，队列中原来的 1 会被移除，因为 3 更大且更晚过期。最终窗口最大值可以直接从队头得到。

时间复杂度：O(n)，每个下标最多入队一次、出队一次
空间复杂度：O(k)，队列中最多保存一个窗口范围内的下标

import heapq
from typing import List


class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        # 先处理前 k 个元素，因为只有凑够 k 个元素后，才形成第一个完整窗口
        # heap 中存的是 (-元素值, 下标)，用负数是为了用 Python 小顶堆模拟大顶堆
        heap = [(-nums[i], i) for i in range(k)]

        # heapify 会把普通列表原地调整成堆结构
        # 调整后 heap[0] 就是当前堆中的最小元，也就是原数组中的最大值
        heapq.heapify(heap)

        # 第一个窗口 [0, k - 1] 的最大值就是堆顶元素
        # 因为堆中存的是负数，所以取出时要再加负号还原
        res = [-heap[0][0]]

        # 从第 k 个元素开始，窗口每次向右滑动一格
        for i in range(k, len(nums)):
            # heappush 会把新元素加入堆，并自动维护堆结构
            heapq.heappush(heap, (-nums[i], i))

            # 当前窗口范围是 [i - k + 1, i]
            # 如果堆顶元素下标 <= i - k，说明它已经在窗口左侧，过期了
            while heap[0][1] <= i - k:
                # heappop 会弹出堆顶元素，并自动维护剩余元素的堆结构
                heapq.heappop(heap)

            # 弹出过期堆顶后，新的堆顶就是当前窗口最大值
            res.append(-heap[0][0])

        return res

import "container/heap"

type Item struct {
	Val   int
	Index int
}

type PriorityQueue []Item

func (pq PriorityQueue) Len() int {
	return len(pq)
}

func (pq PriorityQueue) Less(i, j int) bool {
	return pq[i].Val > pq[j].Val
}

func (pq PriorityQueue) Swap(i, j int) {
	pq[i], pq[j] = pq[j], pq[i]
}

func (pq *PriorityQueue) Push(x interface{}) {
	*pq = append(*pq, x.(Item))
}

func (pq *PriorityQueue) Pop() interface{} {
	old := *pq
	n := len(old)
	item := old[n-1]
	*pq = old[:n-1]
	return item
}

func maxSlidingWindow(nums []int, k int) []int {
	pq := &PriorityQueue{}
	heap.Init(pq)

	for i := 0; i < k; i++ {
		heap.Push(pq, Item{Val: nums[i], Index: i})
	}

	res := []int{(*pq)[0].Val}

	for i := k; i < len(nums); i++ {
		heap.Push(pq, Item{Val: nums[i], Index: i})

		for (*pq)[0].Index <= i-k {
			heap.Pop(pq)
		}

		res = append(res, (*pq)[0].Val)
	}

	return res
}

from collections import deque
from typing import List


class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        # queue 中存的是下标，不是具体的值
        # 下标对应的值会保持从队头到队尾单调递减
        queue = deque()
        res = []

        for ind, num in enumerate(nums):
            # 当前窗口是闭区间 [ind - k + 1, ind]
            # 如果队头下标小于窗口左边界，说明它已经过期
            while queue and queue[0] < ind - k + 1:
                queue.popleft()

            # 如果当前元素大于等于队尾元素，队尾元素以后不可能成为最大值
            # queue[-1] 表示队尾下标，pop() 从队尾移除这些更小的元素
            while queue and nums[queue[-1]] <= num:
                queue.pop()

            # 将当前元素下标加入队尾，作为新的最大值候选
            queue.append(ind)

            # 当窗口大小达到 k 后，队头下标对应的值就是当前窗口最大值
            if ind >= k - 1:
                res.append(nums[queue[0]])

        return res

func maxSlidingWindow(nums []int, k int) []int {
	queue := []int{}
	res := []int{}

	for right, num := range nums {
		for len(queue) > 0 && queue[0] <= right-k {
			queue = queue[1:]
		}

		for len(queue) > 0 && nums[queue[len(queue)-1]] <= num {
			queue = queue[:len(queue)-1]
		}

		queue = append(queue, right)

		if right >= k-1 {
			res = append(res, nums[queue[0]])
		}
	}

	return res
}
