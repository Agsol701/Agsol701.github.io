和为 K 的子数组

May 28, 2026

题目描述

原题链接：https://leetcode.cn/problems/subarray-sum-equals-k/

给你一个整数数组 nums 和一个整数 k，请你统计并返回该数组中和为 k 的子数组个数。

子数组是数组中元素的连续非空序列。

示例 1：

1
2

输入：nums = [1,1,1], k = 2
输出：2

示例 2：

1
2

输入：nums = [1,2,3], k = 3
输出：2

提示：

  • 1 <= nums.length <= 2 * 10^4
  • -1000 <= nums[i] <= 1000
  • -10^7 <= k <= 10^7

解题思路

这道题的核心是统计有多少个连续子数组的和等于 k。

因为数组中可能包含负数，所以不能直接使用普通滑动窗口。普通滑动窗口依赖窗口和随着右指针右移而单调增加、随着左指针右移而单调减少，但当数组中存在负数时，这个单调性不成立。

例如：

1

nums = [1, -1, 1], k = 1

窗口加入 -1 后，窗口和会变小；移出 1 后，窗口和也可能变小。因此只根据 sum < k 移动右指针、sum > k 移动左指针，不能保证不漏答案。

方法一：暴力枚举

最直观的做法是枚举所有子数组：

  1. 固定子数组起点 i
  2. 从 i 开始向右枚举终点 j
  3. 一边枚举一边累加当前子数组和 curSum
  4. 如果 curSum == k，答案加 1

注意不要每次都用 sum(nums[i:j+1]) 重新求和，否则会多一层求和开销。可以在内层循环中维护累加和。

时间复杂度：O(n²)
空间复杂度：O(1)

方法二：前缀和 + 哈希表

前缀和定义为：

1

prefix[i] = nums[0] + nums[1] + ... + nums[i]

j <= i， 如果下标 j 到 i 这一段子数组的和为 k，那么有：

1

prefix[i] - prefix[j - 1] = k

变形后得到：

1

prefix[j - 1] = prefix[i] - k

也就是说，当我们遍历到当前位置，并且当前前缀和为 prefix 时，只需要知道之前出现过多少次 prefix - k，就能知道有多少个以当前位置结尾、和为 k 的子数组。

因此可以用哈希表 prefixCount 记录每个前缀和出现的次数：

  • prefix：从数组开头到当前位置的前缀和
  • prefixCount[prefix]：某个前缀和出现过几次
  • res：和为 k 的子数组数量

具体步骤：

  1. 初始化 prefixCount[0] = 1，表示空前缀出现过一次
  2. 遍历数组，每次把当前数字加入 prefix
  3. 查找 prefix - k 在哈希表中出现过几次，并加到答案中
  4. 将当前 prefix 出现次数加 1

为什么要初始化 prefixCount[0] = 1

这是为了处理从下标 0 开始的子数组。

例如：

1

nums = [1, 2, 3], k = 3

遍历到下标 1 时，当前前缀和是：

1

prefix = 1 + 2 = 3

此时 prefix - k = 0。如果哈希表中提前记录了 0 出现过一次，就表示存在一个“空前缀”，可以得到子数组 [1, 2] 的和为 3。

如果不初始化 prefixCount[0] = 1，所有从下标 0 开始且和刚好为 k 的子数组都会被漏掉。

为什么要先查找再更新当前前缀和

遍历每个数字时，当前 prefix 表示以当前位置结尾的前缀和。

我们要找的是之前出现过的 prefix - k，也就是子数组起点前一个位置的前缀和，所以应该先查找旧的前缀和记录，再把当前 prefix 加入哈希表。

如果先更新当前 prefix，在 k = 0 时可能把当前前缀和也算进去，相当于统计了一个长度为 0 的空子数组，这是不符合题意的。

时间复杂度：O(n)
空间复杂度：O(n)，哈希表最多记录 n + 1 个前缀和

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        res = 0

        for i in range(len(nums)):
            curSum = 0
            for j in range(i, len(nums)):
                curSum += nums[j]
                if curSum == k:
                    res += 1

        return res

func subarraySum(nums []int, k int) int {
	res := 0

	for i := 0; i < len(nums); i++ {
		curSum := 0
		for j := i; j < len(nums); j++ {
			curSum += nums[j]
			if curSum == k {
				res++
			}
		}
	}

	return res
}

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        # prefix_count[某个前缀和] = 这个前缀和之前出现过几次
        # 先放入 0:1，表示还没开始遍历时，空数组的前缀和为 0
        prefix_count = {0: 1}

        # current_prefix_sum 表示从 nums[0] 加到当前位置的总和
        current_prefix_sum = 0

        # answer 表示目前找到的“和为 k 的子数组”数量
        answer = 0

        for num in nums:
            current_prefix_sum += num

            # 如果存在一个之前的前缀和 previous_prefix_sum，满足：
            # current_prefix_sum - previous_prefix_sum == k
            # 那么 previous_prefix_sum 后面到当前位置这一段子数组的和就是 k
            previous_prefix_sum = current_prefix_sum - k

            # previous_prefix_sum 之前出现过几次，就说明有几个子数组以当前位置结尾且和为 k
            answer += prefix_count.get(previous_prefix_sum, 0)

            # 当前前缀和处理完后，再记录到哈希表，供后面的元素使用
            prefix_count[current_prefix_sum] = prefix_count.get(current_prefix_sum, 0) + 1

        return answer

func subarraySum(nums []int, k int) int {
	prefixCount := map[int]int{0: 1}
	prefix := 0
	res := 0

	for _, num := range nums {
		prefix += num
		res += prefixCount[prefix-k]
		prefixCount[prefix]++
	}

	return res
}

复杂度分析

方法 时间复杂度 空间复杂度
暴力枚举 O(n²) O(1)
前缀和 + 哈希表 O(n) O(n)

选择建议：

  • 暴力枚举思路直观，但数据规模较大时会超时
  • 本题数组中可能存在负数，不适合使用普通滑动窗口
  • 前缀和 + 哈希表可以在线性时间内统计答案，是本题推荐解法
