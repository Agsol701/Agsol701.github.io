论文精读：Attention Is All You Need

这篇论文是现代深度学习，尤其是大语言模型时代最重要的论文之一。它提出的 Transformer 架构，把序列建模从长期依赖 RNN/CNN 的范式中解放出来，证明了仅依靠 attention 机制也可以构建高质量、高并行度的序列转导模型。

本文不是逐句翻译论文，而是从学习者和工程实现的角度拆解它：Transformer 为什么出现、每个模块解决什么问题、公式背后的直觉是什么，以及如何把这些概念落到 PyTorch 风格代码中。

1. 论文基本信息

项目 内容
标题 Attention Is All You Need
arXiv 编号 1706.03762v7
版本日期 2023-08-02
作者 Ashish Vaswani, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Lukasz Kaiser, Illia Polosukhin
论文链接 https://arxiv.org/html/1706.03762v7
研究领域 Natural Language Processing, Neural Machine Translation, Sequence Transduction
核心贡献 提出完全基于 attention 的 encoder-decoder 架构 Transformer，用 self-attention 替代 RNN/CNN，在机器翻译中同时提升效果和训练效率。

一句话总结：

Transformer 的关键思想是：序列内部和序列之间的依赖关系，可以主要通过 attention 来建模，不必依赖循环结构或卷积结构。

2. 这篇论文解决了什么问题？

在 Transformer 之前，主流序列转导模型通常是 encoder-decoder 架构，但 encoder 和 decoder 的主体大多依赖 RNN、LSTM、GRU 或 CNN。

这些模型有几个核心限制。

2.1 顺序计算导致训练难以并行化

RNN/LSTM/GRU 按时间步处理序列。第 t 个位置的隐藏状态依赖第 t-1 个位置的隐藏状态，因此同一个样本内部很难并行计算。

这会带来两个问题：

  • 长句子训练慢，因为必须一步一步算。
  • GPU/TPU 的矩阵并行能力无法被充分利用。

机器翻译中句子长度不固定，长句越多，这个瓶颈越明显。

2.2 长距离依赖建模困难

虽然 LSTM/GRU 通过门控机制缓解了梯度消失问题，但远距离 token 之间的信息仍然需要经过很多状态传递。

例如句首的主语影响句尾的动词形式，在 RNN 中信息要跨过许多时间步。路径越长，学习越困难。

2.3 计算路径长度较长

论文第 4 节强调了一个重要指标：任意两个位置之间的信息路径长度。

  • RNN 中，两个距离为 n 的位置之间需要经过 O(n) 步。
  • CNN 中，如果卷积核大小为 k，需要堆叠多层才能覆盖远距离位置。
  • Self-attention 中，任意两个位置可以在一层内直接交互，最大路径长度是 O(1)。

路径短意味着前向信息和反向梯度都更容易传递。

2.4 机器翻译中的效率和效果瓶颈

当时最强的机器翻译系统通常结构复杂，训练成本高。即使 attention 已经被广泛使用，它也通常只是 RNN/CNN 之外的辅助模块。

Transformer 要回答的问题是：

如果 attention 已经能直接建模 token 之间的依赖，是否可以完全去掉 recurrence 和 convolution？

论文的实验结果证明：可以，而且效果更好、训练更快。

3. 核心思想概览

Transformer 最重要的观点包括：

  • 不再依赖 RNN 或 CNN。
  • 完全基于 attention mechanism 建模序列依赖。
  • 仍然使用 encoder-decoder 架构处理序列转导任务。
  • 使用 self-attention 建模同一序列内部 token 之间的关系。
  • 使用 multi-head attention 从多个表示子空间捕获不同关系。
  • 使用 positional encoding 弥补 attention 本身不包含顺序信息的问题。

“Attention is all you need” 的意思不是“模型里只有一个 attention 公式”，也不是“其他组件都不重要”。原始 Transformer 仍然包含 embedding、残差连接、LayerNorm、FFN、dropout、label smoothing 等组件。

它真正表达的是：

对于序列转导任务，核心的依赖建模可以完全交给 attention，而不必再依赖循环或卷积作为主体结构。

从工程角度看，Transformer 把序列建模转换成了大规模矩阵乘法问题。这让模型更适合 GPU 并行训练，也为后来扩大模型参数规模和数据规模奠定了基础。

4. Transformer 整体架构

Transformer 仍然是 encoder-decoder 模型：

  • Encoder 读取源序列，输出每个输入 token 的上下文表示。
  • Decoder 根据已经生成的目标 token 和 encoder 输出，逐步预测下一个 token。

论文中的 base Transformer 使用：

  • N = 6 层 encoder
  • N = 6 层 decoder
  • d_model = 512
  • d_ff = 2048
  • h = 8 个 attention heads
  • 每个 head 的 d_k = d_v = 64

Encoder 由 N 层相同结构堆叠而成。每一层包含两个子层：

  1. Multi-Head Self-Attention

每个子层外部都有：

  • Residual Connection
  • Layer Normalization

可以抽象为：

$$ \text{LayerNorm}(x + \text{Sublayer}(x)) $$

在 encoder self-attention 中，每个 token 都可以关注输入序列中的所有 token。因此，encoder 输出的每个位置都融合了整句上下文信息。

4.2 Decoder

Decoder 也由 N 层相同结构堆叠而成。每层包含三个子层：

  1. Masked Multi-Head Self-Attention
  2. Encoder-Decoder Attention
  3. Position-wise Feed-Forward Network

同样，每个子层外部也使用 residual connection 和 layer normalization。

Decoder 中的 mask 非常关键。训练时，目标序列一次性输入 decoder，但预测第 t 个 token 时，模型不能看到第 t+1、t+2 等未来 token。否则训练时会发生信息泄露，推理时又无法使用未来信息，训练和推理就不一致。

因此 masked self-attention 会把当前位置之后的 attention score 设为负无穷，经过 softmax 后这些位置的权重接近 0。

5. Scaled Dot-Product Attention

论文中的核心公式是：

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$

其中：

  • Q 是 Query，表示“当前 token 想找什么信息”。
  • K 是 Key，表示“每个 token 能被怎样匹配”。
  • V 是 Value，表示“每个 token 真正提供的信息内容”。
  • d_k 是 key/query 的向量维度。

5.1 Q、K、V 分别是什么

在 self-attention 中，Q、K、V 都来自同一个输入序列，只是经过不同的线性变换：

$$ Q = XW^Q,\quad K = XW^K,\quad V = XW^V $$

直观地说，同一个 token 会被投影成三种角色：

  • 作为 query：我现在需要什么上下文？
  • 作为 key：我有什么特征可以被别人匹配？
  • 作为 value：如果别人关注我，我提供什么信息？

5.2 为什么用点积衡量相似度

点积可以衡量两个向量方向的一致程度。q_i \cdot k_j 越大，说明第 i 个 token 的 query 和第 j 个 token 的 key 越匹配。

在矩阵形式中，QK^T 会得到一个 attention score 矩阵：

$$ QK^T \in \mathbb{R}^{\text{seq\_len} \times \text{seq\_len}} $$

第 i 行表示第 i 个 token 对所有 token 的关注分数。

5.3 为什么除以 $\sqrt{d_k}$

当 d_k 较大时，点积结果的方差会变大，softmax 输入可能变得很大或很小，导致 softmax 饱和，梯度变小。

除以 $\sqrt{d_k}$ 的作用是缩放 score，让它们保持在更稳定的范围内。这就是 “Scaled” Dot-Product Attention 中 scaled 的含义。

5.4 softmax 的作用

softmax 把 raw score 转换成概率分布：

  • 每个权重非负。
  • 同一行权重之和为 1。
  • 分数越高的位置权重越大。

于是每个 token 都得到一组“应该从其他 token 读取多少信息”的权重。

5.5 为什么输出是 V 的加权和

attention 的最终目标不是得到相似度，而是聚合信息。

softmax(QK^T / sqrt(d_k)) 得到的是权重矩阵，乘以 V 后，每个位置都会得到所有 value 的加权和。也就是说：

Query 和 Key 决定“看哪里”，Value 决定“拿什么”。

5.6 一个直观类比

可以把 Q/K/V 想成图书馆检索：

  • Query：你输入的检索需求，比如“Transformer 位置编码”。
  • Key：每本书或文章的索引标签。
  • Value：书或文章的实际内容。

检索系统先比较 query 和 key 的匹配程度，再根据匹配分数从 value 中汇总信息。attention 做的就是这个过程，只不过它是端到端可学习的。

6. Multi-Head Attention

单头 attention 只在一个表示空间里计算相关性。Multi-head attention 的做法是把 Q、K、V 投影到多个子空间，让多个 head 并行关注不同关系。

计算流程：

  1. 将输入的 Q、K、V 分别通过线性层投影。
  2. 切分成 h 个 head。
  3. 每个 head 独立计算 scaled dot-product attention。
  4. 拼接所有 head 的输出。
  5. 再经过一个输出线性层。

公式可以写成：

$$ \text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O $$$$ \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V) $$

6.1 为什么多头比单头更强

不同 head 可以学习不同类型的关系：

  • 某些 head 关注相邻词。
  • 某些 head 关注主谓关系。
  • 某些 head 关注长距离依赖。
  • 某些 head 关注标点、边界或特殊 token。

如果只有一个 head，所有关系会被压到一个 attention 分布中，表达能力有限。多头机制让模型可以在不同子空间中并行建模多种关系。

6.2 为什么计算成本仍然可控

论文中 base 模型使用 h = 8，d_model = 512，每个 head 的维度是 64。

虽然 head 数量增加了，但每个 head 的维度变小了。多个小 head 的总计算量与一个完整维度的单头 attention 大致相当。

这也是 multi-head attention 工程上可行的原因：它增强表达能力，但没有把计算成本直接乘以 head 数。

7.1 Encoder Self-Attention

Encoder self-attention 中：

  • Q 来自 encoder 前一层输出。
  • K 来自 encoder 前一层输出。
  • V 来自 encoder 前一层输出。

每个输入 token 可以关注输入序列中的所有 token。这让每个位置都能直接融合全局上下文。

7.2 Decoder Masked Self-Attention

Decoder masked self-attention 中：

  • Q、K、V 都来自 decoder 前一层输出。
  • 每个目标 token 只能关注当前位置以及之前的位置。

mask 的作用是保证自回归生成：

$$ p(y_t \mid y_{也就是说，预测第 t 个 token 时，只能使用源序列 x 和已经生成的目标前缀 y_{<t}。

7.3 Encoder-Decoder Attention

Encoder-decoder attention 中：

  • Q 来自 decoder 前一层输出。
  • K 来自 encoder 输出。
  • V 来自 encoder 输出。

这相当于 decoder 在生成目标 token 时，主动查询源序列信息。它承担了传统 seq2seq attention 的角色：让目标端每一步生成都能对齐和利用源端内容。

8. Position-wise Feed-Forward Network

每个 encoder layer 和 decoder layer 都包含一个 position-wise FFN：

$$ \text{FFN}(x) = \max(0, xW_1 + b_1)W_2 + b_2 $$

它有几个特点：

  • 对每个位置独立应用。
  • 不在不同 token 之间交换信息。
  • 输入和输出维度都是 d_model。
  • 中间层维度是 d_ff。
  • 论文 base 模型中 d_model = 512，d_ff = 2048。

如果 attention 负责“token 之间的信息交互”，FFN 就负责“对每个 token 的表示做非线性变换”。它类似一个共享在所有位置上的两层 MLP，也可以理解为 kernel size 为 1 的卷积。

9. Positional Encoding

Attention 本身对顺序不敏感。对于 self-attention，如果不加入位置信息，模型看到的更像是一组 token，而不是有顺序的句子。

例如：

  • “狗咬人”
  • “人咬狗”

两句话 token 集合相同，但顺序不同，语义完全不同。因此 Transformer 必须注入位置编码。

9.1 Sinusoidal Positional Encoding

论文使用固定的正弦/余弦位置编码：

$$ PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right) $$$$ PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right) $$

其中：

  • pos 是 token 的位置。
  • i 是维度索引。
  • 不同维度对应不同频率。
  • 偶数维使用 sin，奇数维使用 cos。

这种设计让每个位置都有一个确定的向量表示，并且不同频率可以编码不同粒度的位置变化。

论文选择 sinusoidal encoding 的一个动机是：它可能帮助模型泛化到比训练时更长的序列，因为位置编码不是只为训练长度学习出来的查表参数。

9.2 Learned Positional Embedding vs Sinusoidal Positional Encoding

类型 做法 优点 局限
Learned positional embedding 为每个位置学习一个 embedding 简单，适应训练数据 超出训练最大长度时不天然可泛化
Sinusoidal positional encoding 用固定 sin/cos 函数生成 无需学习参数，可能外推到更长长度 表达形式固定，不一定对所有任务最优

论文中也实验了 learned positional embedding，结果与 sinusoidal positional encoding 接近。最终选择 sinusoidal，主要是考虑其外推潜力。

10. 为什么 Self-Attention 有优势？

论文第 4 节从三方面比较 self-attention、recurrent layer 和 convolutional layer：

  • 每层计算复杂度
  • 顺序操作数量
  • 最大路径长度

设：

  • n 是序列长度。
  • d 是表示维度。
  • k 是卷积核大小。
Layer Type 每层复杂度 顺序操作数量 最大路径长度 直观理解
Self-Attention $O(n^2 d)$ $O(1)$ $O(1)$ 所有 token 两两直接交互，并行度高
Recurrent $O(n d^2)$ $O(n)$ $O(n)$ 必须按时间步顺序计算
Convolutional $O(k n d^2)$ $O(1)$ $O(\log_k n)$ 或 $O(n/k)$ 可并行，但远距离依赖需要多层堆叠
Restricted Self-Attention $O(r n d)$ $O(1)$ $O(n/r)$ 只看局部窗口，降低长序列成本

Self-attention 的优势主要在于：

  • 并行化能力强：同一层所有位置可以同时计算。
  • 长距离依赖路径短：任意两个位置一层即可建立联系。
  • 在机器翻译常见设置下，当 n < d 时，复杂度相比 recurrent layer 有优势。

它的代价也很明确：标准 self-attention 对序列长度是二次复杂度 O(n^2)。这就是后来 Longformer、Performer、FlashAttention 等工作持续优化 attention 的原因之一。

11.1 Learning Rate Schedule

论文使用的学习率公式是：

$$ lrate = d_{model}^{-0.5} \cdot \min(step\_num^{-0.5}, step\_num \cdot warmup\_steps^{-1.5}) $$

直观理解：

  • 训练初期，学习率从很小开始线性升高。
  • 经过 warmup steps 后，学习率按 step 的平方根倒数衰减。

warmup 的作用是让训练初期更稳定。模型刚初始化时，参数和激活分布都还不稳定，如果一开始学习率太大，容易导致训练震荡甚至发散。warmup 相当于先低速启动，等模型进入较稳定区域后再逐步提高学习率。

11.2 Label Smoothing

普通交叉熵会把正确类别当成概率 1，其他类别概率 0。Label smoothing 会把目标分布稍微“软化”，例如正确类别不是 1，而是 0.9，剩下的概率分给其他类别。

这会让模型不要过度自信。论文中提到它会让 perplexity 变差一些，但能提升 accuracy 和 BLEU。

import math
import torch
import torch.nn as nn
import torch.nn.functional as F


class ScaledDotProductAttention(nn.Module):
    def forward(self, Q, K, V, mask=None):
        """
        Q: [batch_size, num_heads, q_len, d_k]
        K: [batch_size, num_heads, k_len, d_k]
        V: [batch_size, num_heads, v_len, d_v]
        mask: [batch_size, 1, q_len, k_len] or None
        """
        d_k = Q.size(-1)

        # scores: [batch_size, num_heads, q_len, k_len]
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)

        if mask is not None:
            scores = scores.masked_fill(mask == 0, float("-inf"))

        # attn: [batch_size, num_heads, q_len, k_len]
        attn = F.softmax(scores, dim=-1)

        # output: [batch_size, num_heads, q_len, d_v]
        output = torch.matmul(attn, V)
        return output, attn

关键点：

  • QK^T 产生 attention scores。
  • mask 通常在 softmax 前应用。
  • softmax 后乘以 V，得到加权聚合结果。

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        assert d_model % num_heads == 0

        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads

        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

        self.attention = ScaledDotProductAttention()

    def split_heads(self, x):
        """
        x: [batch_size, seq_len, d_model]
        return: [batch_size, num_heads, seq_len, d_k]
        """
        batch_size, seq_len, _ = x.size()
        x = x.view(batch_size, seq_len, self.num_heads, self.d_k)
        return x.transpose(1, 2)

    def combine_heads(self, x):
        """
        x: [batch_size, num_heads, seq_len, d_k]
        return: [batch_size, seq_len, d_model]
        """
        batch_size, _, seq_len, _ = x.size()
        x = x.transpose(1, 2).contiguous()
        return x.view(batch_size, seq_len, self.d_model)

    def forward(self, query, key, value, mask=None):
        """
        query: [batch_size, q_len, d_model]
        key:   [batch_size, k_len, d_model]
        value: [batch_size, v_len, d_model]
        """
        Q = self.split_heads(self.W_q(query))
        K = self.split_heads(self.W_k(key))
        V = self.split_heads(self.W_v(value))

        # context: [batch_size, num_heads, q_len, d_k]
        context, attn = self.attention(Q, K, V, mask)

        # context: [batch_size, q_len, d_model]
        context = self.combine_heads(context)

        # output: [batch_size, q_len, d_model]
        output = self.W_o(context)
        return output, attn

工程上最容易出错的是 shape 变换。多头注意力通常要在 [batch_size, seq_len, d_model] 和 [batch_size, num_heads, seq_len, d_k] 之间切换。

class PositionwiseFeedForward(nn.Module):
    def __init__(self, d_model, d_ff, dropout=0.1):
        super().__init__()
        self.fc1 = nn.Linear(d_model, d_ff)
        self.fc2 = nn.Linear(d_ff, d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        """
        x: [batch_size, seq_len, d_model]
        """
        x = self.fc1(x)       # [batch_size, seq_len, d_ff]
        x = F.relu(x)
        x = self.dropout(x)
        x = self.fc2(x)       # [batch_size, seq_len, d_model]
        return x

FFN 不改变序列长度，也不混合不同位置的信息。它只对每个 token 的向量表示做非线性变换。

class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()

        # pe: [max_len, d_model]
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len).unsqueeze(1).float()

        div_term = torch.exp(
            torch.arange(0, d_model, 2).float()
            * (-math.log(10000.0) / d_model)
        )

        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)

        # pe: [1, max_len, d_model]
        self.register_buffer("pe", pe.unsqueeze(0))

    def forward(self, x):
        """
        x: [batch_size, seq_len, d_model]
        """
        seq_len = x.size(1)
        return x + self.pe[:, :seq_len, :]

register_buffer 表示 pe 不是可训练参数，但会跟随模型保存和迁移设备。

class EncoderLayer(nn.Module):
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads)
        self.ffn = PositionwiseFeedForward(d_model, d_ff, dropout)

        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, src_mask=None):
        """
        x: [batch_size, src_len, d_model]
        src_mask: padding mask
        """
        attn_out, attn = self.self_attn(x, x, x, src_mask)
        x = self.norm1(x + self.dropout(attn_out))

        ffn_out = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_out))
        return x, attn

这里的 self_attn(x, x, x) 表示 Q、K、V 都来自同一个序列。

class DecoderLayer(nn.Module):
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads)
        self.cross_attn = MultiHeadAttention(d_model, num_heads)
        self.ffn = PositionwiseFeedForward(d_model, d_ff, dropout)

        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, memory, tgt_mask=None, src_mask=None):
        """
        x: [batch_size, tgt_len, d_model]
        memory: [batch_size, src_len, d_model], encoder output
        tgt_mask: causal mask + target padding mask
        src_mask: source padding mask
        """
        self_attn_out, self_attn = self.self_attn(x, x, x, tgt_mask)
        x = self.norm1(x + self.dropout(self_attn_out))

        # Q comes from decoder, K/V come from encoder memory.
        cross_attn_out, cross_attn = self.cross_attn(x, memory, memory, src_mask)
        x = self.norm2(x + self.dropout(cross_attn_out))

        ffn_out = self.ffn(x)
        x = self.norm3(x + self.dropout(ffn_out))
        return x, self_attn, cross_attn

Decoder layer 的核心差异在于有两类 attention：

  • self-attention：看目标端已生成前缀。
  • cross-attention：看源端 encoder 输出。

16. 常见误区

16.1 Attention 不是简单的“权重可视化”

Attention weight 可以帮助理解模型关注了哪些位置，但它不是严格的人类解释。模型真正的表示还经过 value 聚合、残差、FFN、多层叠加等处理。

16.2 Self-Attention 并不天然知道顺序

Self-attention 如果没有位置编码，对 token 顺序不敏感。位置编码不是装饰，而是 Transformer 能处理序列顺序的必要组件。

16.3 Multi-head 不是简单重复多个 attention

不同 head 有不同的线性投影参数，它们在不同子空间计算 attention。它不是把同一个 attention 复制多份，而是让模型学习多种关系视角。

16.4 Decoder mask 不是 padding mask

Decoder causal mask 用来屏蔽未来 token，保证自回归生成。

Padding mask 用来屏蔽 padding token，避免模型关注无效位置。

二者目的不同，但在实现中经常会组合使用。

16.5 Transformer 原论文主要验证的是机器翻译任务

今天提到 Transformer，很多人会直接联想到大语言模型预训练。但原论文主要实验对象是机器翻译和 constituency parsing，不是 GPT 式大规模自回归预训练。

16.6 原始 Transformer 和现代 GPT/BERT 架构有差异

原始 Transformer 是 encoder-decoder。

  • BERT 主要使用 encoder-only 架构。
  • GPT 主要使用 decoder-only 架构。
  • T5 延续 encoder-decoder 思路，但使用文本到文本预训练范式。

现代 LLM 还常使用 RoPE、RMSNorm、SwiGLU、KV Cache、FlashAttention 等改进，这些都不是原论文中的设计。

17. 读完这篇论文后的学习路线

  1. 手写 Scaled Dot-Product Attention，重点检查 QK^T、mask、softmax、乘 V 的 shape。
  2. 手写 Multi-Head Attention，重点理解 split heads 和 concat heads。
  3. 实现一个 mini Transformer encoder，在小文本分类任务上跑通。
  4. 阅读 BERT 论文，理解 encoder-only Transformer 和 masked language modeling。
  5. 阅读 GPT 系列相关资料，理解 decoder-only Transformer 和 causal language modeling。
  6. 学习现代 LLM 中的改进，如 RoPE、RMSNorm、SwiGLU、KV Cache、FlashAttention。

如果目标是写代码，建议不要一开始就实现完整 Transformer。更好的路径是：

  1. 先实现 attention 单元测试。
  2. 再实现 multi-head attention。
  3. 再拼 encoder layer。
  4. 最后堆叠成完整模型。

这样每一步都能用 shape 和数值测试验证，不容易在复杂模型里迷失。

18. 总结

《Attention Is All You Need》的历史意义在于，它重新定义了序列建模的核心算子。

在它之前，attention 更多是 RNN/CNN seq2seq 模型中的增强模块；在它之后，attention 成为模型架构的主体。Transformer 把序列建模变成了高度并行的矩阵计算，把长距离依赖压缩到极短路径，并用 multi-head attention 提升了表达能力。

从今天看，Transformer 不只是一个机器翻译模型，而是现代大语言模型、视觉 Transformer、多模态模型的共同基础。学习这篇论文，最重要的不是记住每个 BLEU 数字，而是理解一个更深层的架构思想：

当模型可以通过 attention 直接、并行、可学习地建立任意位置之间的联系时，序列建模的主要瓶颈就从“如何逐步传递信息”转向了“如何高效组织和扩展注意力计算”。

这也是为什么 Transformer 至今仍然是 AI 工程中最值得反复精读和手写实现的架构之一。
