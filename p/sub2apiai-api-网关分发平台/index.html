Sub2API：AI API 网关分发平台

Jun 12, 2026

项目简介

Sub2API 是一个开源的 AI API 网关平台，用于统一分发和管理 AI 订阅服务的 API 配额。它将 Claude、OpenAI、Gemini 等上游 AI 服务统一在一个端点后面，通过平台生成的 API Key 进行访问，同时处理认证、计费、负载均衡和请求转发。

核心特性

  • 多账号管理（支持 OAuth 和 API Key 上游账号）
  • API Key 分发与管理
  • Token 级别精确计费
  • 智能调度与会话粘性
  • 并发控制与速率限制
  • 内置支付系统（支付宝、微信、Stripe）
  • Web 管理面板
  • Simple Mode（个人开发者/内部团队精简模式）

技术栈

组件 技术
后端 Go, Gin, Ent
前端 Vue 3, Vite, TailwindCSS
数据库 PostgreSQL 15+
缓存 Redis 7+

API 端点

端点 用途
/v1/messages Claude API 转发
/v1beta/ Gemini API 转发

部署

方式一：脚本安装

前置条件：Linux（amd64/arm64）、PostgreSQL 15+、Redis 7+、root 权限。

1

curl -sSL https://raw.githubusercontent.com/Wei-Shaw/sub2api/main/deploy/install.sh | sudo bash

启动服务：

1
2

sudo systemctl start sub2api
sudo systemctl enable sub2api

安装完成后访问 http://YOUR_SERVER_IP:8080 进入设置向导。

卸载：

1

curl -sSL https://raw.githubusercontent.com/Wei-Shaw/sub2api/main/deploy/install.sh | sudo bash -s -- uninstall -y

方式二：Docker Compose（推荐）

前置条件

  • Docker 20.10+
  • Docker Compose（V2 插件或 V1 独立版均可）

macOS 安装 Docker

安装 Docker Desktop for Mac，已内置 Docker Compose V2。

验证安装 

1
2

docker --version
docker compose version 2>/dev/null || docker-compose --version 2>/dev/null

部署步骤

macOS（M1/M2/M3 Apple Silicon）

  1. 安装 Docker Desktop for Mac 并启动
  2. 执行部署脚本：
1
2

mkdir -p ~/sub2api-deploy && cd ~/sub2api-deploy
curl -sSL https://raw.githubusercontent.com/Wei-Shaw/sub2api/main/deploy/docker-deploy.sh | bash
  1. 按需编辑 .env（密码等已自动生成），然后启动：
1

docker compose up -d
  1. 查看自动生成的管理员密码：
1

docker compose logs sub2api | grep -i password
  1. 浏览器访问 http://localhost:8080 进入管理面板

macOS 本地部署的优势：OAuth 授权回调地址为 localhost，浏览器可直接接收回调，无需端口转发。

Ubuntu / Linux 服务器 

1
2

mkdir -p sub2api-deploy && cd sub2api-deploy
curl -sSL https://raw.githubusercontent.com/Wei-Shaw/sub2api/main/deploy/docker-deploy.sh | bash

脚本会自动生成安全凭证（JWT_SECRET、TOTP_ENCRYPTION_KEY、POSTGRES_PASSWORD）并写入 .env 文件。

按需修改 .env 配置（如设置 Redis 密码）：

1
2

# 编辑 .env
REDIS_PASSWORD=your_password

注意：如果使用 Docker Compose V1（docker-compose 命令），compose 文件中的 ${VAR:+...} 语法不兼容。若设置了 REDIS_PASSWORD，需要将 redis 的 command 改为硬编码：

1

command: "redis-server --save 60 1 --appendonly yes --appendfsync everysec --requirepass your_password"

启动服务：

1
2
3
4
5

# Docker Compose V2
docker compose up -d

# 或 Docker Compose V1
docker-compose up -d

查看管理员密码（首次启动自动生成）：

1

docker compose logs sub2api | grep -i password

访问 http://YOUR_SERVER_IP:8080 进入管理面板。

远程部署 OAuth 注意事项：OpenAI OAuth 回调地址为 localhost:1455，如果通过远程 IP 访问面板进行 OAuth 授权，回调无法到达服务端。建议在本地（macOS）部署 sub2api 完成 OAuth 授权，或在服务器上使用带桌面环境的浏览器操作。

升级 

1

docker compose pull && docker compose up -d

方式三：源码编译

前置条件：Go 1.21+、Node.js 18+、PostgreSQL 15+、Redis 7+。

1
2
3
4
5
6
7

git clone https://github.com/Wei-Shaw/sub2api.git && cd sub2api
npm install -g pnpm
cd frontend && pnpm install && pnpm run build
cd ../backend && go build -tags embed -o sub2api ./cmd/server
cp ../deploy/config.example.yaml ./config.yaml
# 编辑 config.yaml 后启动
./sub2api

-tags embed 会将前端静态资源嵌入 Go 二进制文件。

配置

环境变量（Docker）

变量 说明
POSTGRES_PASSWORD 数据库密码（必填）
JWT_SECRET JWT 密钥，重启后保持登录
TOTP_ENCRYPTION_KEY 2FA 密钥，重启后保持有效
ADMIN_EMAIL 管理员邮箱
ADMIN_PASSWORD 管理员密码
SERVER_PORT 端口（默认 8080）
RUN_MODE=simple 启用 Simple Mode

生成密钥：

1

openssl rand -hex 32

使用

基本流程

  1. 部署完成后访问 Web 管理面板（默认端口 8080）
  2. 添加上游 AI 账号（Claude/OpenAI/Gemini）
  3. 创建 API Key 分发给下游用户
  4. 下游用户使用生成的 Key 调用对应端点

配合 Claude Code 使用 

1
2

export ANTHROPIC_BASE_URL="http://your-server:8080"
export ANTHROPIC_AUTH_TOKEN="sk-xxx"

Nginx 反向代理

使用 Nginx 代理时，需在 http 块中添加：

1

underscores_in_headers on;

避免 Nginx 丢弃 session_id 等下划线 header，影响会话粘性路由。

Simple Mode

面向个人开发者或内部团队，隐藏计费和 SaaS 功能：

1
2

RUN_MODE=simple
SIMPLE_MODE_CONFIRM=true  # 生产环境必须

注意事项

  • 项目 README 声明：使用可能违反上游服务商条款，仅供技术学习与研究，风险自负
  • 生产环境请勿启用 HTTP（不安全），应配置 HTTPS
