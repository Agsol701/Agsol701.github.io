找出字符串中第一个匹配项的下标

Apr 21, 2026

题目描述

原题链接：https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/

给你两个字符串 haystack 和 needle ，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回 -1 。

示例 1：

1
2
3
4

输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 在下标 0 和 6 处匹配。
第一个匹配项的下标是 0，所以返回 0 。

示例 2：

1
2
3

输入：haystack = "leetcode", needle = "leeto"
输出：-1
解释："leeto" 没有在 "leetcode" 中出现，所以返回 -1 。

提示：

  • 1 <= haystack.length, needle.length <= 10^4
  • haystack 和 needle 仅由小写英文字符组成

解题思路

方法一：暴力法

这道题最直接的做法就是暴力匹配。

我们从 haystack 的每一个可能起点开始，判断从这个位置出发，后面的子串是否和 needle 完全相同。

具体做法：

  1. 枚举匹配起点 i
  2. 从 i 开始逐个比较 haystack[i + j] 和 needle[j]
  3. 如果某一位不同，就说明这个起点不行，继续尝试下一个起点
  4. 如果 needle 的所有字符都匹配成功，就返回当前起点 i

需要注意的是，起点 i 最多只需要枚举到 len(haystack) - len(needle)，因为更靠后的位置已经不可能容纳完整的 needle 了。

例如：

  • haystack = "sadbutsad"
  • needle = "sad"

当 i = 0 时：

  • haystack[0:3] = "sad"
  • 和 needle 完全相同

所以直接返回 0。

时间复杂度：O((n - m + 1) * m)，最坏情况下可以看作 O(nm)
空间复杂度：O(1)

方法二：KMP

如果想把匹配过程优化到线性时间，就可以使用 KMP 算法。

KMP 的核心思想是：

  • 当匹配失败时，不需要让模式串回到开头重新比较
  • 利用模式串本身的前后缀信息，直接跳到下一个可能匹配的位置

这里需要先构造一个 next 数组，也常叫前缀函数数组或部分匹配表。

next[i] 表示：

  • 在模式串 needle[0:i+1] 中
  • 最长的“相同前缀和后缀”的长度

例如模式串是 aabaaf：

  • 当某一位匹配失败时
  • 可以根据前面已经匹配成功的部分
  • 直接把模式串滑动到合适位置

这样就避免了很多重复比较。

KMP 的过程分为两步：

  1. 先计算模式串 needle 的 next 数组
  2. 再用两个指针扫描 haystack 和 needle

匹配时：

  • 如果当前字符相同，两个指针一起前进
  • 如果不同，就根据 next 数组回退模式串指针
  • 如果模式串全部匹配完成，就返回匹配起点

KMP 的优势在于整个匹配过程中，文本串和模式串指针都不会重复无意义地回退，因此总时间复杂度是线性的。

KMP 时间复杂度：O(n + m)
KMP 空间复杂度：O(m)

class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n, m = len(haystack), len(needle)

        for i in range(n - m + 1):
            if haystack[i:i + m] == needle:
                return i

        return -1

func strStr(haystack string, needle string) int {
	n, m := len(haystack), len(needle)

	for i := 0; i <= n-m; i++ {
		j := 0
		for j < m && haystack[i+j] == needle[j] {
			j++
		}

		if j == m {
			return i
		}
	}

	return -1
}

class SolutionKMP:
    def strStr(self, haystack: str, needle: str) -> int:
        def build_next(pattern: str) -> list[int]:
            next_arr = [0] * len(pattern)
            j = 0

            for i in range(1, len(pattern)):
                while j > 0 and pattern[i] != pattern[j]:
                    j = next_arr[j - 1]

                if pattern[i] == pattern[j]:
                    j += 1

                next_arr[i] = j

            return next_arr

        next_arr = build_next(needle)
        j = 0

        for i in range(len(haystack)):
            while j > 0 and haystack[i] != needle[j]:
                j = next_arr[j - 1]

            if haystack[i] == needle[j]:
                j += 1

            if j == len(needle):
                return i - len(needle) + 1

        return -1

func strStrKMP(haystack string, needle string) int {
	next := buildNext(needle)
	j := 0

	for i := 0; i < len(haystack); i++ {
		for j > 0 && haystack[i] != needle[j] {
			j = next[j-1]
		}

		if haystack[i] == needle[j] {
			j++
		}

		if j == len(needle) {
			return i - len(needle) + 1
		}
	}

	return -1
}

func buildNext(pattern string) []int {
	next := make([]int, len(pattern))
	j := 0

	for i := 1; i < len(pattern); i++ {
		for j > 0 && pattern[i] != pattern[j] {
			j = next[j-1]
		}

		if pattern[i] == pattern[j] {
			j++
		}

		next[i] = j
	}

	return next
}
