package main

import "fmt"

func main() {
	var a [5]int    // 元素类型 int，零值是 0
	var b [3]string // 元素类型 string，零值是 ""
	var c [2]bool   // 元素类型 bool，零值是 false

	fmt.Println(a)        // [0 0 0 0 0]
	fmt.Println(b)        // ["" "" ""]
	fmt.Printf("%q\n", b) // 用 %q 打印字符串的引号形式
	fmt.Println(len(b))   // 打印数组长度
	fmt.Println(c)        // [false false]
}

Go语言nil特性

  • nil 标识符是不能比较的
  • nil 不是关键字或保留字
  • 不同类型 nil 的指针是一样的
  • 不同类型的 nil 是不能比较的
  • 两个相同类型的 nil 值也可能无法比较
  • nil 是常见引用类型的零值

变量声明

Go的变量需要声明之后才能使用，同一作用域内不支持重复声明。 在函数内部，可以使用简短声明 var 语句。 在函数外部，变量声明语句中必须指明类型。如果声明变量时未指明类型，则变量类型根据赋值进行推断。

变量的初始化

Go语言在声明变量的时候，会自动对变量对应的内存区域进行初始化操作。每个变量会被初始化成其类型的默认值，例如： 整型和浮点型变量的默认值为0。 字符串变量的默认值为空字符串。 布尔型变量默认为false。 切片、函数、指针变量的默认为nil。

// 短变量声明（海象运算符）这个只能在函数内部使用

iota常量

Golang 中的 常量 声明可以使用 iota 常量生成器初始化。Go 语言常量(iota)生成器用于生成一组以相似规则初始化的常量，但是不用每行都写一遍初始化表达式。 在一个 const 声明语句中，在第一个声明的常量所在的行，iota 将会被置为 0，然后在每一个有常量声明的行加一。 iota在遇到新的const关键字的时候会置零。

package main

import "fmt"

func main() {
	const (
		start   = iota
		monday  = iota
		tuesday = iota
		wednesday
		thursday
		friday
		saturday
		sunday
	)
	fmt.Println(monday, tuesday, wednesday, thursday, friday, saturday, sunday)
	const (
		B = 1 << (10 * iota)
		KB
		MB
		GB
		TB
		PB
	)
	fmt.Println(B, KB, MB, GB, TB, PB)
	const (
		a = 2 * iota
		b
		_ //iota=2的时候被跳过
		c
		d
	)
	fmt.Println(a, b, c, d)
}

new
new 函数只接受一个参数，这个参数是一个 Golang 的 数据类型，并且返回一个指向该类型内存地址的指针。同时 new 函数会把分配的内存置为零，也就是类型的零值。
func new(Type) *Type

make
make 也是用于内存分配的，make 函数的 t 参数必须是 chan（通道）、map（字典）、slice（切片）中的一个。
make 和 new 不同，它只用于 chan、map 以及 slice 的内存创建，而且它返回的类型就是这三个类型本身，而不是他们的指针类型，因为这三种类型就是引用类型，所以就没有必要返回他们的指针了。
func make(t Type, size ...IntegerType) Type // (type len cap)
  • make 只能用来分配及初始化类型为 slice、map、chan 的数据，而 new 可以分配任意类型的数据。
  • new 分配返回的是指针，即类型 *Type。make 返回引用，即 Type。
  • new 分配的空间被清零。make 分配空间后，会进行初始化。
