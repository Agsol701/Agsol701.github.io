解决文件名乱码问题 💡

Git 状态显示的文件名是乱码，这通常是因为您的终端或 Git 配置没有正确处理文件名中的中文或特殊字符。

例如：

  • \344\272\214\345\217\211\346\240\221\345\220\216\345\272\217\351\201\215\345\216\206.md 实际可能是 二叉树后序遍历.md。

您可以通过以下方式让 Git 直接显示原始文件名，而不是乱码编码：

临时修改配置（推荐）

在当前 Git 仓库中执行以下命令，告诉 Git 不使用引号和 C 语言风格的转义来显示文件名：

Bash

1

git config --local core.quotepath false

执行后，再次运行 git status，文件名的显示应该就会正常了。
