有序数组的平方

Apr 05, 2026

题目描述

原题链接：https://leetcode.cn/problems/squares-of-a-sorted-array/ 给你一个按 非递减顺序 排序的整数数组 nums，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。

示例 1：

输入：nums = [-4,-1,0,3,10] 输出：[0,1,9,16,100] 解释：平方后，数组变为 [16,1,0,9,100] 排序后，数组变为 [0,1,9,16,100] 示例 2：

输入：nums = [-7,-3,2,3,11] 输出：[4,9,9,49,121]

提示：

1 <= nums.length <= 104 -104 <= nums[i] <= 104 nums 已按 非递减顺序 排序

进阶：

请你设计时间复杂度为 O(n) 的算法解决本问题

解题思路

双指针法

由于数组已经按非递减顺序排列，所以虽然平方之后元素大小关系会发生变化，但平方后的最大值一定只会出现在原数组的两端。

原因是：

  • 负数平方后会变成正数，而且绝对值越大，平方后也越大
  • 正数平方后同样是数值越大，平方后越大
  • 因此，平方后的最大值只可能来自最左边的负数或最右边的正数

所以可以使用双指针：

  • left 指向数组左端
  • right 指向数组右端
  • res_right 指向结果数组当前应该填入的位置，从后往前填充

每次比较 nums[left]^2 和 nums[right]^2：

  • 如果左边更大，就把左边平方后的值放到结果数组末尾，然后 left += 1
  • 否则就把右边平方后的值放到结果数组末尾，然后 right -= 1

这样每次都能确定当前最大的平方值，并且从后往前构造出有序结果数组。

时间复杂度：O(n)
空间复杂度：O(n)

from typing import List
import copy


class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        res_list = copy.copy(nums)
        left, right = 0, len(nums) - 1
        res_right = len(nums) - 1
        while left <= right:
            if nums[left] * nums[left] > nums[right] * nums[right]:
                res_list[res_right] = nums[left] * nums[left]
                left += 1
            else:
                res_list[res_right] = nums[right] * nums[right]
                right -= 1
            res_right -= 1
        return res_list

func sortedSquares(nums []int) []int {
	res_nums := make([]int, len(nums), len(nums))
	left, right, res_right := 0, len(nums)-1, len(nums)-1
	for left <= right {
		if nums[left]*nums[left] > nums[right]*nums[right] {
			res_nums[res_right] = nums[left] * nums[left]
			left++
		} else {
			res_nums[res_right] = nums[right] * nums[right]
			right--
		}
		res_right--
	}
	return res_nums
}
