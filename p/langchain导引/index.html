说明

这是一个跟着官方文档走一遍的笔记（v0.3），由于文档的顺序个人感觉有点乱，不太好啃，所有这里记录一下文档学习过程。

学习顺序

从 Introduction 开始简单了解 langchain 的相关信息 接下来是Conceptual guide 来学习基本概念，其中先看下Concepts让这些概念在脑子里有一个印象，后面学习的过程中有疑问的组件或方法的时候，火来看Glossary how_to guides 中来学习各个部分的细节用法，而文档中的 tutorials 则是具体应用，需要用到前面的技术细节。
进入到 Tutorials 后，主要学习 Get started 和 Orchestration Get started 是基础模块的使用，Orchestration 则是通过编排实现实际问题。
