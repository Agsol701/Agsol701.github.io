找到字符串中所有字母异位词

May 28, 2026

题目描述

原题链接：https://leetcode.cn/problems/find-all-anagrams-in-a-string/

给定两个字符串 s 和 p，找到 s 中所有 p 的字母异位词的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

字母异位词指由相同字母重新排列形成的字符串，包括每个字母出现的次数也必须相同。

示例 1：

输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
解释：
起始索引等于 0 的子串是 "cba"，它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac"，它是 "abc" 的异位词。

输入：s = "abab", p = "ab"
输出：[0,1,2]
解释：
起始索引等于 0 的子串是 "ab"，它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba"，它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab"，它是 "ab" 的异位词。

提示：

  • 1 <= s.length, p.length <= 3 * 10^4
  • s 和 p 仅包含小写字母

解题思路

这道题的核心是：在 s 中找到所有长度等于 p.length，并且字符频次和 p 完全相同的子串。

因为字母异位词只关心字符出现次数，不关心字符顺序，所以可以先统计 p 的字符频次，然后用滑动窗口维护 s 中长度为 len(p) 的子串频次。

方法一：滑动窗口 + 计数数组

题目说明 s 和 p 都只包含小写字母，因此可以使用长度为 26 的数组统计字符频次：

  • need：记录 p 中每个字符出现的次数
  • window：记录当前窗口中每个字符出现的次数
  • left、right：维护当前窗口范围
  • res：记录所有符合条件的起始下标

具体做法：

  1. 先统计字符串 p 的字符频次，得到 need
  2. 遍历字符串 s，不断把 s[right] 加入窗口
  3. 当窗口长度大于 len(p) 时，移除 s[left]，并右移 left
  4. 当窗口长度等于 len(p) 且 window == need 时，说明当前窗口是一个字母异位词，把 left 加入答案

由于窗口长度始终不会超过 len(p)，每次比较两个长度为 26 的数组，比较成本可以看作常数。

时间复杂度：O(n * 26)，可以看作 O(n)
空间复杂度：O(1)，计数数组长度固定为 26

为什么窗口长度要固定为 len(p)

字母异位词必须和原字符串包含完全相同的字符及次数，因此长度也一定相同。

例如 p = "abc"，那么只有长度为 3 的子串才可能是它的字母异位词：

1

3
4

s = "cbaebabacd"
p = "abc"

窗口 [0, 2] => "cba"，长度为 3，是异位词
窗口 [1, 3] => "bae"，长度为 3，不是异位词

如果窗口长度小于 len(p)，字符数量不够；如果窗口长度大于 len(p)，字符数量又太多。因此每次只需要检查长度刚好为 len(p) 的窗口。

方法二：滑动窗口 + 有效字符数

方法一每次窗口长度等于 len(p) 时，都要比较两个数组。虽然数组长度固定为 26，已经是常数时间，但还可以用 valid 进一步优化判断逻辑。

核心思路：

  • need 记录 p 中每个字符需要出现的次数
  • window 记录当前窗口中每个字符出现的次数
  • valid 表示当前有多少种字符的出现次数已经满足 need

当 valid == need.size() 且窗口长度等于 len(p) 时，说明当前窗口中所有需要的字符都刚好满足要求，当前 left 就是一个答案。

这个写法更接近通用滑动窗口模板，适合解决包含更大字符集或需要动态判断窗口合法性的题目。

时间复杂度：O(n)
空间复杂度：O(1)，本题只有小写字母；如果字符集扩大，则为 O(k)

方法零：排序窗口（原始写法）

这个写法的思路很直观：先把 p 排序得到标准字符串，然后枚举 s 中每个长度为 len(p) 的窗口，把窗口排序后和 p 的排序结果比较。如果相同，说明当前窗口是一个字母异位词。

需要注意两点：

  • 循环条件要写成 right <= len(s)，否则会漏掉最后一个窗口
  • 提交时要去掉调试用的 print

这种写法容易理解，但每个窗口都要排序，时间复杂度较高。

时间复杂度：O((n - m + 1) * mlogm)，其中 n = len(s)，m = len(p)
空间复杂度：O(m)，排序窗口时需要额外空间

from typing import List


class Solution:
    def sort_str(self, s: str) -> str:
        return ''.join(sorted(s))

    def findAnagrams(self, s: str, p: str) -> List[int]:
        ret = []
        left, right = 0, len(p)
        sorted_p = self.sort_str(p)

        while right <= len(s):
            if self.sort_str(s[left:right]) == sorted_p:
                ret.append(left)
            left += 1
            right += 1

        return ret

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        if len(s) < len(p):
            return []

        need = [0] * 26
        window = [0] * 26
        res = []
        pLen = len(p)

        for ch in p:
            need[ord(ch) - ord('a')] += 1

        left = 0
        for right in range(len(s)):
            window[ord(s[right]) - ord('a')] += 1

            if right - left + 1 > pLen:
                window[ord(s[left]) - ord('a')] -= 1
                left += 1

            if right - left + 1 == pLen and window == need:
                res.append(left)

        return res

func findAnagrams(s string, p string) []int {
	if len(s) < len(p) {
		return []int{}
	}

	var need [26]int
	var window [26]int
	res := []int{}
	pLen := len(p)

	for i := 0; i < len(p); i++ {
		need[p[i]-'a']++
	}

	left := 0
	for right := 0; right < len(s); right++ {
		window[s[right]-'a']++

		if right-left+1 > pLen {
			window[s[left]-'a']--
			left++
		}

		if right-left+1 == pLen && window == need {
			res = append(res, left)
		}
	}

	return res
}

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        need = {}
        window = {}
        res = []

        for ch in p:
            need[ch] = need.get(ch, 0) + 1

        left = 0
        valid = 0

        for right in range(len(s)):
            ch = s[right]
            if ch in need:
                window[ch] = window.get(ch, 0) + 1
                if window[ch] == need[ch]:
                    valid += 1

            while right - left + 1 >= len(p):
                if valid == len(need):
                    res.append(left)

                removeCh = s[left]
                left += 1
                if removeCh in need:
                    if window[removeCh] == need[removeCh]:
                        valid -= 1
                    window[removeCh] -= 1

        return res

func findAnagrams(s string, p string) []int {
	need := map[byte]int{}
	window := map[byte]int{}
	res := []int{}

	for i := 0; i < len(p); i++ {
		need[p[i]]++
	}

	left := 0
	valid := 0

	for right := 0; right < len(s); right++ {
		ch := s[right]
		if _, ok := need[ch]; ok {
			window[ch]++
			if window[ch] == need[ch] {
				valid++
			}
		}

		for right-left+1 >= len(p) {
			if valid == len(need) {
				res = append(res, left)
			}

			removeCh := s[left]
			left++
			if _, ok := need[removeCh]; ok {
				if window[removeCh] == need[removeCh] {
					valid--
				}
				window[removeCh]--
			}
		}
	}

	return res
}

复杂度分析

方法 时间复杂度 空间复杂度
排序窗口 O((n - m + 1) * mlogm) O(m)
滑动窗口 + 计数数组 O(n) O(1)
滑动窗口 + 有效字符数 O(n) O(1)

选择建议：

  • 排序窗口写法直观，适合理解题意，但会重复排序每个窗口，效率较低
  • 本题只包含小写字母，推荐使用计数数组，代码更短，判断也更直接
  • valid 写法更接近通用滑动窗口模板，适合迁移到字符集不固定的问题
  • 无论哪种优化方法，本质都是维护一个长度为 len(p) 的窗口，并判断窗口内字符频次是否和 p 相同
