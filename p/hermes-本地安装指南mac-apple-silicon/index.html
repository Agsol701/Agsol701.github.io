Hermes 本地安装指南（Mac Apple Silicon）

Apr 25, 2026

适用环境

本文适用于以下环境：

  • macOS（Apple Silicon，例如 M1 / M2 / M3）
  • zsh shell
  • 希望在本机安装并运行 Hermes CLI

如果你使用的是 Intel Mac 或 Linux，部分依赖和路径可能需要调整。

安装前检查

在正式安装前，建议先确认基础环境没有问题。

1. 检查系统架构

执行：

1

uname -m

期望输出：

1

arm64

如果输出不是 arm64，说明当前机器不是 Apple Silicon，本文步骤不一定完全适用。

2. 检查 Homebrew

执行：

1
2

brew --version
which brew

期望结果：

  • brew --version 能正常输出版本号
  • which brew 输出类似：
1

/opt/homebrew/bin/brew

如果 brew 不存在，建议先安装 Homebrew，再继续后续步骤。

3. 检查 Git

执行：

1

git --version

如果命令不存在，可以执行：

1

brew install git

安装 Hermes

目前在 Apple Silicon Mac 上，最省事的方式是直接使用官方安装脚本。

执行：

1

curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

这个脚本通常会自动准备 Hermes 运行所需的基础依赖，包括：

  • uv
  • Python 3.11
  • Node.js 22
  • ripgrep
  • ffmpeg
  • hermes

如果你的网络环境不稳定，安装过程可能会稍慢一些，属于正常现象。

刷新 shell 配置

安装完成后，重新加载 zsh 配置：

1

source ~/.zshrc

然后验证是否已经安装成功：

1

hermes version

如果能正常输出版本号，说明 CLI 已经可用了。

配置模型

Hermes 安装完成后，还需要选择模型提供方。

执行：

1

hermes model

然后根据自己的情况选择 provider，例如：

  • OpenAI
  • Anthropic
  • OpenRouter

如果所选 provider 需要 API Key，再按提示完成配置即可。

安装后检查

建议再做一次健康检查：

1
2

hermes doctor
hermes status

如果这两个命令都没有明显报错，就可以继续启动 Hermes：

1

hermes

常见问题

1. hermes: command not found

通常是因为当前 shell 还没有重新加载配置。

可以先执行：

1

source ~/.zshrc

如果还是不行，重新打开一个终端窗口再试一次。

2. 安装过程中依赖下载失败

这类问题多数和网络有关，不一定是 Hermes 本身的问题。可以：

  • 稍后重试一次
  • 确认本机能正常访问 GitHub
  • 确认 Homebrew 和基础开发工具已经可用

3. 模型可用但无法正常对话

这通常不是安装问题，而是模型配置问题。建议重点检查：

  • provider 是否选对
  • API Key 是否已正确配置
  • 账号额度或权限是否正常

小结

在 M1 MacBook 上安装 Hermes，最推荐的方式是直接运行官方安装脚本。

整体流程可以概括为：

  1. 确认当前机器是 Apple Silicon
  2. 检查 Homebrew 和 Git
  3. 执行官方安装脚本
  4. 重新加载 shell 配置
  5. 选择模型 provider
  6. 用 doctor 和 status 做安装验证
