在极摩客 K8 迷你主机上安装 Ubuntu 完整指南

May 20, 2026

目标硬件：极摩客 K8 迷你主机

项目 规格
CPU AMD Ryzen 7 8845HS（Zen4, 8核16线程）
GPU AMD Radeon 780M 核显
内存 DDR5 5600MHz（双通道插槽）
存储 M.2 NVMe SSD（PCIe 4.0）
WiFi Intel AX210 WiFi 6E + 蓝牙 5.3
网口 2.5G 有线网口
视频输出 HDMI 2.1 × 2 + USB-C（DP Alt）
USB USB 3.2 × 4，USB-C × 1

注：具体配置以你购买的版本为准，核心安装流程一致。

准备工作

购买 U 盘

  • 容量：8GB 以上（推荐 16GB）
  • 接口：USB 3.0（K8 的前面板有 USB 3.2 口，写入更快）
  • 品牌推荐：闪迪、金士顿等主流品牌即可

下载 Ubuntu 镜像

  • 访问 https://ubuntu.com/download/desktop
  • 选择 Ubuntu 24.04 LTS 或更新版本
    • 内核 6.8+ 对 Ryzen 8000 系列和 RDNA3 核显（780M）支持更完善
    • 如果 24.04 遇到硬件兼容问题，考虑使用 24.10 或更新版本（内核更新）
  • 下载 .iso 文件（约 5GB）

# 查看 U 盘设备号
diskutil list

# 卸载 U 盘（假设是 /dev/disk2）
diskutil unmountDisk /dev/disk2

# 写入镜像（注意用 rdisk 更快）
sudo dd if=~/Downloads/ubuntu-24.04-desktop-amd64.iso of=/dev/rdisk2 bs=4m status=progress

# 完成后弹出
diskutil eject /dev/disk2

使用图形工具

  • macOS：下载 balenaEtcher，选择 ISO → 选择 U 盘 → Flash
  • Windows：使用 Rufus

BIOS 设置（极摩客 K8）

  1. 将 U 盘插入 K8 的 USB 口
  2. 开机时连续按 Del 或 F2 进入 BIOS（GMK 系列通常为 Del 键）
  3. 按 F7 切换到高级模式（如有）
  4. 设置以下选项：
    • Secure Boot → Disabled（关闭安全启动）
    • Boot Mode → UEFI（确认为 UEFI 模式）
    • Boot Option #1 → 选择你的 U 盘
  5. 按 F10 保存并退出

提示：也可以开机时按 F11 或 F12 直接进入一次性启动菜单选择 U 盘，无需修改 BIOS 设置。

安装 Ubuntu

  1. 从 U 盘启动后，选择 Try or Install Ubuntu
  2. 选择语言：中文（简体）
  3. 选择键盘布局
  4. 连接网络：
    • 优先使用 2.5G 有线网口（即插即用，安装更稳定）
    • WiFi（Intel AX210）在安装界面通常也能直接识别
  5. 选择安装类型：
    • 正常安装：包含浏览器、办公软件等
    • 最小安装：只有基础工具（推荐，后续按需装）
  6. 勾选：
    • 安装时下载更新
    • 安装第三方软件（重要：包含 AMD GPU 固件和 WiFi 驱动）

磁盘分区

K8 通常配备单块 NVMe SSD，以 512GB 为例：

简单方案（推荐）

选择「清除整个磁盘并安装 Ubuntu」，系统自动分区。

手动分区方案（512GB SSD 参考）

分区 挂载点 大小 文件系统
EFI /boot/efi 512MB FAT32
根分区 / 80GB ext4
家目录 /home 剩余空间（~415GB） ext4
交换分区 swap 16GB（与内存等大） swap

如果内存 32GB 且不使用休眠，swap 可以设为 8GB 节省空间。

完成安装

  1. 设置时区：Shanghai
  2. 创建用户名和密码
  3. 等待安装完成（NVMe SSD 上约 5-10 分钟）
  4. 提示重启时，拔出 U 盘，按回车

常见问题

安装时黑屏或花屏

在 GRUB 菜单选择 Install Ubuntu 时按 e，在 quiet splash 后添加：

nomodeset

按 Ctrl+X 启动。安装完成后更新系统及固件即可恢复正常显示。

HDMI 无输出

  • 优先尝试不同的 HDMI 口（K8 有两个 HDMI 2.1）
  • 或使用 USB-C 转 DP 输出
  • 确保显示器支持 UEFI 分辨率输出

安装后无法从 SSD 启动

进入 BIOS 确认 Boot Option #1 已切换为内置 SSD（而非 U 盘）。

休眠/睡眠唤醒问题

AMD 平台偶尔有 S3 睡眠兼容问题，可切换为 s2idle：

1
2
3
4
5
6

# 查看当前睡眠模式
cat /sys/power/mem_sleep

# 如需强制 s2idle，添加内核参数
sudo sed -i 's/GRUB_CMDLINE_LINUX_DEFAULT="/GRUB_CMDLINE_LINUX_DEFAULT="mem_sleep_default=s2idle /' /etc/default/grub
sudo update-grub

注意事项

  • 备份数据：如果 K8 上已有 Windows 系统且有重要数据，安装前务必备份
  • 双系统：如果要保留预装 Windows，安装时选择「与 Windows 共存」
  • BIOS 更新：安装前建议到极摩客官网检查是否有 BIOS 更新，新 BIOS 可能改善 Linux 兼容性
  • 验证 ISO：下载后可用 sha256sum 校验，防止文件损坏
