缺失的第一个正数

May 30, 2026

题目描述

原题链接：https://leetcode.cn/problems/first-missing-positive/

给你一个未排序的整数数组 nums，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 O(n) 并且只使用常数级别额外空间的解决方案。

示例 1：

1
2
3

输入：nums = [1,2,0]
输出：3
解释：范围 [1,2] 中的数字都在数组中。

示例 2：

1
2
3

输入：nums = [3,4,-1,1]
输出：2
解释：1 在数组中，但 2 没有。

示例 3：

1
2
3

输入：nums = [7,8,9,11,12]
输出：1
解释：最小的正整数 1 没有出现。

提示：

  • 1 <= nums.length <= 10^5
  • -2^31 <= nums[i] <= 2^31 - 1

解题思路

这道题要求找到数组中没有出现的最小正整数。

如果数组长度是 n，那么答案一定在 [1, n + 1] 之间：

  • 如果 1 到 n 都出现了，答案就是 n + 1
  • 否则答案就是 [1, n] 中第一个没有出现的数字

因此我们只需要关心范围 [1, n] 内的数字，其他负数、0、大于 n 的数字都不会影响答案。

方法一：哈希集合

最直观的做法是把数组中的数字全部放入哈希集合中，然后从 1 开始依次检查：

  1. 遍历数组，将所有数字加入集合
  2. 从 1 到 n 依次判断当前数字是否存在
  3. 第一个不存在的正整数就是答案
  4. 如果 1 到 n 都存在，则返回 n + 1

这种方法思路简单，但需要额外的哈希集合空间。

时间复杂度：O(n)
空间复杂度：O(n)

方法二：原地哈希

题目要求常数级别额外空间，可以把原数组本身当作哈希表使用。

对于一个数字 x，如果 1 <= x <= n，它应该放在下标 x - 1 的位置上。例如：

1
2
3

数字 1 应该放在 nums[0]
数字 2 应该放在 nums[1]
数字 3 应该放在 nums[2]

遍历数组时，如果当前数字 nums[i] 满足：

  • nums[i] 在 [1, n] 范围内
  • nums[i] 没有出现在它应该在的位置上

就把 nums[i] 交换到下标 nums[i] - 1 的位置。

注意这里要用 while，因为交换之后当前位置可能又来了一个新的有效数字，也需要继续放到正确位置。

完成整理后，再次遍历数组：

  • 如果 nums[i] != i + 1，说明数字 i + 1 没有出现，直接返回 i + 1
  • 如果所有位置都满足 nums[i] == i + 1，说明 1 到 n 都出现了，返回 n + 1

例如数组：

1

nums = [3,4,-1,1]

整理后应该变成：

1

nums = [1,-1,3,4]

第一个不满足 nums[i] == i + 1 的位置是下标 1，所以缺失的最小正整数是 2。

时间复杂度：O(n)，每个数字最多被交换到正确位置一次
空间复杂度：O(1)

class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        numSet = set(nums)
        n = len(nums)

        for num in range(1, n + 1):
            if num not in numSet:
                return num

        return n + 1

func firstMissingPositive(nums []int) int {
	seen := make(map[int]bool)
	for _, num := range nums {
		seen[num] = true
	}

	n := len(nums)
	for num := 1; num <= n; num++ {
		if !seen[num] {
			return num
		}
	}

	return n + 1
}

class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)

        for i in range(n):
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                targetIndex = nums[i] - 1
                nums[i], nums[targetIndex] = nums[targetIndex], nums[i]

        for i in range(n):
            if nums[i] != i + 1:
                return i + 1

        return n + 1

func firstMissingPositive(nums []int) int {
	n := len(nums)

	for i := 0; i < n; i++ {
		for nums[i] >= 1 && nums[i] <= n && nums[nums[i]-1] != nums[i] {
			targetIndex := nums[i] - 1
			nums[i], nums[targetIndex] = nums[targetIndex], nums[i]
		}
	}

	for i := 0; i < n; i++ {
		if nums[i] != i+1 {
			return i + 1
		}
	}

	return n + 1
}

总结

本题的关键是利用数组长度 n 推出答案范围一定在 [1, n + 1]。

  • 哈希集合写法最容易理解，但空间复杂度是 O(n)
  • 原地哈希把数字 x 放到下标 x - 1，可以在 O(n) 时间和 O(1) 额外空间内完成
  • 交换时需要判断目标位置是否已经是相同数字，避免重复数字导致死循环
