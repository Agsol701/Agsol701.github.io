环形链表 II

Apr 16, 2026

题目描述

原题链接：https://leetcode.cn/problems/linked-list-cycle-ii/

给定一个链表的头节点 head，返回链表开始入环的第一个节点。如果链表无环，则返回 null。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置，下标从 0 开始。如果 pos 是 -1，则表示链表中没有环。

注意：pos 不作为参数进行传递，仅仅是为了标识链表的实际情况。

不允许修改链表。

示例 1：

1
2
3

输入：head = [3,2,0,-4], pos = 1
输出：返回索引为 1 的链表节点
解释：链表中有一个环，其尾部连接到第二个节点。

示例 2：

1
2
3

输入：head = [1,2], pos = 0
输出：返回索引为 0 的链表节点
解释：链表中有一个环，其尾部连接到第一个节点。

示例 3：

1
2
3

输入：head = [1], pos = -1
输出：null
解释：链表中没有环。

提示：

  • 链表中节点的数目范围在 [0, 10^4] 内
  • -10^5 <= Node.val <= 10^5
  • pos 的值为 -1 或者链表中的一个有效索引

进阶：

你是否可以使用 O(1) 空间解决此题？

解题思路

这道题可以有两种常见解法。

方法一：哈希表

最直观的思路是记录每个访问过的节点。

从头节点开始遍历链表：

  • 如果当前节点没有出现过，就把它加入集合
  • 如果当前节点已经出现在集合中，说明这是第一次重复访问到的节点，也就是入环的第一个节点
  • 如果遍历到 nil / None，说明链表无环

这种方法很好理解，但需要额外空间保存访问过的节点。

时间复杂度：O(n)
空间复杂度：O(n)

方法二：快慢指针

如果想满足进阶要求，可以使用快慢指针，也就是 Floyd 判环算法。

先判断链表是否有环：

  • slow 每次走一步
  • fast 每次走两步
  • 如果链表有环，slow 和 fast 一定会在环内相遇
  • 如果 fast 或 fast.next 走到 nil / None，说明链表无环

找到相遇点后，还需要找到入环的第一个节点。

假设：

  • 从链表头节点到入环点的距离是 x
  • 从入环点到快慢指针相遇点的距离是 y
  • 从相遇点再回到入环点的距离是 z

快指针走过的距离是慢指针的两倍：

1
2
3

slow = x + y
fast = x + y + n * (y + z)
fast = 2 * slow

整理后可以得到：

1

x = n * (y + z) - y

也就是说，从头节点出发走 x 步，和从相遇点出发绕环走若干步，最终都会到达入环点。

因此，在快慢指针相遇后：

  1. 让一个指针 ptr 从 head 出发
  2. 让另一个指针 slow 从相遇点出发
  3. 两个指针每次都走一步
  4. 它们第一次相遇的位置，就是链表入环的第一个节点

时间复杂度：O(n)
空间复杂度：O(1)

from typing import Optional


class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None


class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        visited = set()
        cur = head

        while cur:
            if cur in visited:
                return cur
            visited.add(cur)
            cur = cur.next

        return None

type ListNode struct {
	Val  int
	Next *ListNode
}

func detectCycle(head *ListNode) *ListNode {
	visited := map[*ListNode]bool{}
	cur := head

	for cur != nil {
		if visited[cur] {
			return cur
		}
		visited[cur] = true
		cur = cur.Next
	}

	return nil
}

from typing import Optional


class ListNode:
    def __init__(self, x):
        self.val = x
        self.next = None


class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head
        has_cycle = False

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                has_cycle = True
                break

        if not has_cycle:
            return None

        ptr = head
        while ptr != slow:
            ptr = ptr.next
            slow = slow.next

        return ptr

type ListNode struct {
	Val  int
	Next *ListNode
}

func detectCycle(head *ListNode) *ListNode {
	slow, fast := head, head
	hasCycle := false

	for fast != nil && fast.Next != nil {
		slow = slow.Next
		fast = fast.Next.Next

		if slow == fast {
			hasCycle = true
			break
		}
	}
    
	//也可以用 	if fast == nil || fast.Next == nil 来判断
	if !hasCycle {
		return nil
	}

	ptr := head
	for ptr != slow {
		ptr = ptr.Next
		slow = slow.Next
	}

	return ptr
}
