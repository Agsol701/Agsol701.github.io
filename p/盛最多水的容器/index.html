盛最多水的容器

May 26, 2026

题目描述

原题链接：https://leetcode.cn/problems/container-with-most-water/

给定一个长度为 n 的整数数组 height。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i])。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

说明：不能倾斜容器。

示例 1：

1
2
3

输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：选择高度为 8 和 7 的两条线，宽度为 7，面积为 7 * 7 = 49。

示例 2：

1
2

输入：height = [1,1]
输出：1

提示：

  • n == height.length
  • 2 <= n <= 10^5
  • 0 <= height[i] <= 10^4

解题思路

这道题要求在数组中选择两条线，组成一个可以盛水的容器。

如果选择下标 left 和 right 两条线，那么容器能盛的水量为：

1
2

面积 = 宽度 * 高度
     = (right - left) * min(height[left], height[right])

其中：

  • 宽度由两个下标之间的距离决定
  • 高度由两条线中较短的一条决定，因为水不能超过短板

方法一：暴力枚举

最直观的做法是枚举所有可能的两条线：

  1. 使用两层循环枚举 left 和 right
  2. 每次计算当前容器面积
  3. 维护最大面积

时间复杂度：O(n²)，两层循环会超时
空间复杂度：O(1)

方法二：双指针

使用两个指针分别指向数组两端：

  • left 指向最左边
  • right 指向最右边

每次计算当前两个指针组成的容器面积，然后移动较短的那一边。

为什么移动较短的一边？

因为当前面积由较短的高度决定。假设：

1

height[left] < height[right]

此时容器高度由 height[left] 决定。如果移动右指针，宽度一定变小，而左边短板没有变，面积不可能变大。

所以只有移动左指针，才有机会遇到更高的短板，从而得到更大的面积。

做法如下：

  1. 初始化 left = 0，right = len(height) - 1
  2. 当 left < right 时，计算当前面积
  3. 更新最大面积
  4. 如果 height[left] < height[right]，移动 left
  5. 否则移动 right

时间复杂度：O(n)，每个指针最多移动 n 次
空间复杂度：O(1)

class Solution:
    def maxArea(self, height: List[int]) -> int:
        maxArea = 0

        for left in range(len(height)):
            for right in range(left + 1, len(height)):
                width = right - left
                curHeight = min(height[left], height[right])
                maxArea = max(maxArea, width * curHeight)

        return maxArea

func maxArea(height []int) int {
	maxArea := 0

	for left := 0; left < len(height); left++ {
		for right := left + 1; right < len(height); right++ {
			width := right - left
			curHeight := min(height[left], height[right])
			if width*curHeight > maxArea {
				maxArea = width * curHeight
			}
		}
	}

	return maxArea
}

func min(a int, b int) int {
	if a < b {
		return a
	}
	return b
}

class Solution:
    def maxArea(self, height: List[int]) -> int:
        left = 0
        right = len(height) - 1
        maxArea = 0

        while left < right:
            width = right - left
            curHeight = min(height[left], height[right])
            maxArea = max(maxArea, width * curHeight)

            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return maxArea

func maxArea(height []int) int {
	left := 0
	right := len(height) - 1
	maxArea := 0

	for left < right {
		width := right - left
		curHeight := min(height[left], height[right])
		if width*curHeight > maxArea {
			maxArea = width * curHeight
		}

		if height[left] < height[right] {
			left++
		} else {
			right--
		}
	}

	return maxArea
}

func min(a int, b int) int {
	if a < b {
		return a
	}
	return b
}

复杂度分析

方法 时间复杂度 空间复杂度
暴力枚举 O(n²) O(1)
双指针 O(n) O(1)

选择建议：

  • 暴力枚举思路简单，但 n 最大为 10^5，一定会超时
  • 双指针每次移动较短的一边，可以在保留可能更优答案的同时缩小搜索范围，是本题的推荐解法
