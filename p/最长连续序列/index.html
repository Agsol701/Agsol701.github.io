最长连续序列

May 26, 2026

题目描述

原题链接：https://leetcode.cn/problems/longest-consecutive-sequence/

给定一个未排序的整数数组 nums，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1：

1
2
3

输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]，长度为 4。

示例 2：

1

输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9

示例 3：

1
2

输入：nums = [1,0,1,2]
输出：3

提示：

  • 0 <= nums.length <= 10^5
  • -10^9 <= nums[i] <= 10^9

解题思路

核心目标：在无序数组中找到最长的一段连续整数，例如 1, 2, 3, 4。

如果先排序，再遍历统计连续长度，思路很直观，但排序时间复杂度是 O(nlogn)，不满足题目要求的 O(n)。

要做到 O(n)，关键是利用哈希集合实现 O(1) 的查找。

方法一：排序

先对数组排序，然后遍历排序后的数组：

  1. 如果当前数字和前一个数字相同，说明是重复元素，跳过
  2. 如果当前数字等于前一个数字加 1，说明连续长度加 1
  3. 否则连续中断，重新从长度 1 开始统计
  4. 维护最大连续长度

时间复杂度：O(nlogn)，主要来自排序
空间复杂度：O(logn) 到 O(n)，取决于排序算法

方法二：哈希集合

将所有数字放入哈希集合中，这样就可以快速判断某个数字是否存在。

关键优化是：只从连续序列的起点开始查找。

对于一个数字 num：

  • 如果 num - 1 存在，说明 num 不是序列起点，跳过
  • 如果 num - 1 不存在，说明 num 可能是一段连续序列的起点

然后从这个起点开始，不断检查 num + 1、num + 2、num + 3 是否存在，统计这一段连续序列的长度。

例如数组：

1

[100, 4, 200, 1, 3, 2]

放入集合后：

  • 1 的前一个数 0 不存在，所以从 1 开始扩展：1 -> 2 -> 3 -> 4，长度为 4
  • 2、3、4 的前一个数都存在，所以它们不会重复作为起点计算
  • 100 和 200 各自长度为 1

这样每个数字最多被访问常数次，因此整体时间复杂度是 O(n)。

时间复杂度：O(n)
空间复杂度：O(n)，哈希集合最多存储 n 个元素

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        if not nums:
            return 0

        nums.sort()
        maxLen = 1
        curLen = 1

        for i in range(1, len(nums)):
            if nums[i] == nums[i - 1]:
                continue
            elif nums[i] == nums[i - 1] + 1:
                curLen += 1
            else:
                curLen = 1
            maxLen = max(maxLen, curLen)

        return maxLen

func longestConsecutive(nums []int) int {
	if len(nums) == 0 {
		return 0
	}

	sort.Ints(nums)
	maxLen := 1
	curLen := 1

	for i := 1; i < len(nums); i++ {
		if nums[i] == nums[i-1] {
			continue
		} else if nums[i] == nums[i-1]+1 {
			curLen++
		} else {
			curLen = 1
		}
		if curLen > maxLen {
			maxLen = curLen
		}
	}

	return maxLen
}

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        numSet = set(nums)
        # maxLen 从 0 开始，是为了兼容 nums 为空数组的情况，此时最长连续序列长度应为 0
        maxLen = 0

        for num in numSet:
            if num - 1 not in numSet:
                curNum = num
                # curLen 从 1 开始，是因为当前 num 本身已经是一段连续序列的第一个数字
                curLen = 1

                while curNum + 1 in numSet:
                    curNum += 1
                    curLen += 1

                maxLen = max(maxLen, curLen)

        return maxLen

func longestConsecutive(nums []int) int {
	numSet := make(map[int]bool)
	for _, num := range nums {
		numSet[num] = true
	}

	maxLen := 0
	for num := range numSet {
		if !numSet[num-1] {
			curNum := num
			curLen := 1

			for numSet[curNum+1] {
				curNum++
				curLen++
			}

			if curLen > maxLen {
				maxLen = curLen
			}
		}
	}

	return maxLen
}
