轮转数组

May 30, 2026

题目描述

原题链接：https://leetcode.cn/problems/rotate-array/

给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。

示例 1：

1
2
3
4
5
6

输入：nums = [1,2,3,4,5,6,7], k = 3
输出：[5,6,7,1,2,3,4]
解释：
向右轮转 1 步：[7,1,2,3,4,5,6]
向右轮转 2 步：[6,7,1,2,3,4,5]
向右轮转 3 步：[5,6,7,1,2,3,4]

示例 2：

1
2
3
4
5

输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
解释：
向右轮转 1 步：[99,-1,-100,3]
向右轮转 2 步：[3,99,-1,-100]

提示：

  • 1 <= nums.length <= 10^5
  • -2^31 <= nums[i] <= 2^31 - 1
  • 0 <= k <= 10^5

进阶：

尽可能想出更多的解决方案，至少有三种不同的方法可以解决这个问题。你可以使用空间复杂度为 O(1) 的原地算法解决这个问题吗？

解题思路

这道题要求把数组整体向右移动 k 个位置，并且在 LeetCode 中要求原地修改 nums。

需要注意的是，k 可能大于数组长度。因为向右轮转 n 次后数组会回到原样，所以真正需要移动的次数是：

1

k = k % n

其中 n 是数组长度。

方法一：使用额外数组

最直观的做法是新建一个长度相同的数组 res，把每个元素放到它轮转后的新位置。

对于原数组下标 i，向右轮转 k 位后的新下标是：

1

(i + k) % n

具体步骤：

  1. 计算数组长度 n
  2. 将 k 更新为 k % n
  3. 创建一个长度为 n 的新数组 res
  4. 遍历原数组，把 nums[i] 放到 res[(i + k) % n]
  5. 再把 res 中的元素复制回 nums

时间复杂度：O(n)
空间复杂度：O(n)

方法二：三次反转

如果要做到原地修改，可以使用三次反转。

以 nums = [1,2,3,4,5,6,7]，k = 3 为例：

1
2
3
4

原数组：       [1,2,3,4,5,6,7]
整体反转：     [7,6,5,4,3,2,1]
反转前 k 个：  [5,6,7,4,3,2,1]
反转剩余部分： [5,6,7,1,2,3,4]

为什么这样可行？

向右轮转 k 位后，原数组末尾的 k 个元素会移动到数组前面，前面的 n-k 个元素会移动到后面。

通过整体反转，可以先把后半部分放到前面；再分别反转前 k 个元素和后 n-k 个元素，就能恢复每一部分内部的正确顺序。

具体步骤：

  1. 将 k 更新为 k % n
  2. 反转整个数组 [0, n - 1]
  3. 反转前 k 个元素 [0, k - 1]
  4. 反转剩余元素 [k, n - 1]

时间复杂度：O(n)
空间复杂度：O(1)

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        res = [0] * n

        for i in range(n):
            res[(i + k) % n] = nums[i]

        for i in range(n):
            nums[i] = res[i]

func rotate(nums []int, k int) {
	n := len(nums)
	k %= n
	res := make([]int, n)

	for i := 0; i < n; i++ {
		res[(i+k)%n] = nums[i]
	}

	for i := 0; i < n; i++ {
		nums[i] = res[i]
	}
}

class Solution:
    def reverse_list(self, nums: List[int], left, right) -> None:
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1

    def rotate(self, nums: List[int], k: int) -> None:
        k %= len(nums)
        self.reverse_list(nums, 0, len(nums) - k - 1)
        self.reverse_list(nums, len(nums) - k, len(nums) - 1)
        self.reverse_list(nums, 0, len(nums) - 1)

func rotate(nums []int, k int) {
	n := len(nums)
	k %= n

	reverse := func(left int, right int) {
		for left < right {
			nums[left], nums[right] = nums[right], nums[left]
			left++
			right--
		}
	}

	reverse(0, n-1)
	reverse(0, k-1)
	reverse(k, n-1)
}

复杂度分析

方法 时间复杂度 空间复杂度
使用额外数组 O(n) O(n)
三次反转 O(n) O(1)

选择建议：

  • 使用额外数组思路最直观，容易理解，但需要额外空间
  • 三次反转可以做到原地修改，空间复杂度为 O(1)，是本题更推荐的解法
