collections.deque

Nov 19, 2025

collections.deque()是 Python 标准库 collections 模块中的一个非常实用的容器。它实现了双端队列（double-ended queue），通常简称为 deque（发音为 “deck”）。

Deque 的主要特点是：

  • 它支持线程安全、快速地从两端添加（append）和弹出（pop）元素。
  • 它的底层实现类似于一个双向链表，因此，在队列的头部和尾部操作（插入和删除）的时间复杂度都是 $O(1)$。
  • 与 list 相比，list 在头部插入或删除元素（如 list.insert(0, x) 或 list.pop(0)）的时间复杂度是 $O(n)$，因为需要移动所有后续元素。

📚 collections.deque() 基本用法介绍

1. 创建 Deque

你可以选择传入一个可迭代对象来初始化 deque，也可以创建一个空 deque。

  • 语法: deque([iterable[, maxlen]])
    • iterable (可选): 用于初始化 deque 的数据。
    • maxlen (可选): 指定 deque 的最大长度。如果设置了最大长度，当新元素添加到已满的 deque 时，另一端的元素会自动被移除。

from collections import deque

# 1. 创建一个空 deque
d1 = deque()
print(f"d1: {d1}")  # 输出: d1: deque([])

# 2. 从一个列表创建 deque
d2 = deque(['a', 'b', 'c'])
print(f"d2: {d2}")  # 输出: d2: deque(['a', 'b', 'c'])

# 3. 创建一个带有最大长度的 deque
d3 = deque(maxlen=3)
print(f"d3 (maxlen=3): {d3.maxlen}") # 输出: d3 (maxlen=3): 3

2. 添加元素 (Adding Elements)

Deque 最常用的功能就是从两端添加元素。

方法 描述
append(x) 在 右侧/尾部 添加元素 $x$。
appendleft(x) 在 左侧/头部 添加元素 $x$。
extend(iterable) 在 右侧/尾部 扩展，加入一个可迭代对象的所有元素。
extendleft(iterable) 在 左侧/头部 扩展，加入一个可迭代对象的所有元素。注意：iterable 中的元素会反序加入。

d = deque([1, 2])

# 1. 右侧添加
d.append(3)
print(f"append(3): {d}")  # deque([1, 2, 3])

# 2. 左侧添加
d.appendleft(0)
print(f"appendleft(0): {d}")  # deque([0, 1, 2, 3])

# 3. 右侧扩展
d.extend([4, 5])
print(f"extend([4, 5]): {d}")  # deque([0, 1, 2, 3, 4, 5])

# 4. 左侧扩展 (注意：元素是反序加入的)
d.extendleft([-2, -1]) # 先加入 -1，再加入 -2
print(f"extendleft([-2, -1]): {d}") # deque([-2, -1, 0, 1, 2, 3, 4, 5])

d_max = deque([1, 2, 3], maxlen=3)
print(f"初始: {d_max}")  # deque([1, 2, 3])

# 在右侧添加一个新元素 4
# 头部元素 1 会自动弹出
d_max.append(4)
print(f"append(4): {d_max}")  # deque([2, 3, 4])

# 在左侧添加一个新元素 0
# 尾部元素 4 会自动弹出
d_max.appendleft(0)
print(f"appendleft(0): {d_max}")  # deque([0, 2, 3])

3. 删除元素 (Removing Elements)

删除元素同样支持从两端操作。

方法 描述
pop() 从 右侧/尾部 移除并返回一个元素。如果 deque 为空，则抛出 IndexError。
popleft() 从 左侧/头部 移除并返回一个元素。如果 deque 为空，则抛出 IndexError。
remove(value) 移除找到的第一个 value。如果找不到，则抛出 ValueError。
clear() 移除所有元素。

d = deque(['a', 'b', 'c', 'd'])

# 1. 右侧弹出
right_item = d.pop()
print(f"pop() 弹出: {right_item}, d: {d}")  # pop() 弹出: d, d: deque(['a', 'b', 'c'])

# 2. 左侧弹出
left_item = d.popleft()
print(f"popleft() 弹出: {left_item}, d: {d}")  # popleft() 弹出: a, d: deque(['b', 'c'])

# 3. 移除特定值
d.remove('c')
print(f"remove('c'): {d}")  # remove('c'): deque(['b'])

4. 旋转 (Rotating)

这是 deque 特有的一个非常实用的功能。

  • 语法: rotate(n=1)
    • 将 deque 旋转 $n$ 步。
    • 如果 $n > 0$（正数），元素从右侧移动到左侧。
    • 如果 $n < 0$（负数），元素从左侧移动到右侧。
    • 默认 $n=1$。

d = deque([1, 2, 3, 4, 5])

# 1. 正向旋转 1 步 (右 -> 左: 5 移动到头部)
d.rotate(1)
print(f"rotate(1): {d}")  # deque([5, 1, 2, 3, 4])

# 2. 负向旋转 2 步 (左 -> 右: 5, 1 移动到尾部)
d.rotate(-2)
print(f"rotate(-2): {d}")  # deque([2, 3, 4, 5, 1])

5. 其他操作

方法 描述
d[i] 通过索引访问元素 (索引访问和修改的性能是 $O(n)$，不如 $O(1)$ 的列表)。
d[i] = x 修改索引 $i$ 处的元素。
len(d) 返回元素个数。
count(x) 统计元素 $x$ 出现的次数。
index(x) 返回 $x$ 第一次出现的索引。

🎯 典型应用场景

1. 高效队列和栈

由于 deque 支持两端 $O(1)$ 的添加和弹出操作，它可以用作高效的：

  • 队列 (Queue - FIFO)：使用 append() (入队) 和 popleft() (出队)。
  • 栈 (Stack - LIFO)：使用 append() (入栈) 和 pop() (出栈)。

2. 固定大小的历史记录

利用 maxlen 属性，deque 是保存“最近 $N$ 个元素”或“固定大小历史记录”的完美选择。

def track_history(item, history_size=3):
    """只保留最近3次的访问记录"""
    history = deque(maxlen=history_size)
    
    # 假设历史记录已经有数据
    history.extend(['a', 'b'])
    print(f"当前历史: {history}") # 当前历史: deque(['a', 'b'], maxlen=3)
    
    # 添加新记录
    history.append(item)
    print(f"添加 {item} 后: {history}") 
    
    history.append('d')
    print(f"再次添加 'd': {history}") # 再次添加 'd': deque(['b', 'c', 'd'], maxlen=3)
    
track_history('c')

3. 滑动窗口算法

在处理序列数据时，需要维护一个固定大小的窗口，deque 的 $O(1)$ 头部和尾部操作使其成为实现滑动窗口或双端单调队列的理想工具。
