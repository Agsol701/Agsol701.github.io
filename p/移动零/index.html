移动零

May 26, 2026

题目描述

原题链接：https://leetcode.cn/problems/move-zeroes/

给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意，必须在不复制数组的情况下原地对数组进行操作。

示例 1：

1
2

输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]

示例 2：

1
2

输入：nums = [0]
输出：[0]

提示：

  • 1 <= nums.length <= 10^4
  • -2^31 <= nums[i] <= 2^31 - 1

进阶：

你能尽量减少完成的操作次数吗？

解题思路

这道题要求把所有 0 移动到数组末尾，并且保持非零元素的相对顺序，同时还要求原地修改数组。

可以把问题理解为：先把所有非零元素按原顺序移动到数组前面，剩下的位置自然都应该填成 0。

方法一：两次遍历

使用一个指针 slow 表示下一个非零元素应该放置的位置：

  1. 第一次遍历数组，把所有非零元素依次写入数组前面
  2. 此时 [0, slow) 区间都是非零元素，并且相对顺序保持不变
  3. 第二次遍历，从 slow 开始到数组末尾全部填充为 0

例如：

1

nums = [0,1,0,3,12]

第一次遍历后：

1
2

nums = [1,3,12,3,12]
slow = 3

第二次填充 0 后：

1

nums = [1,3,12,0,0]

时间复杂度：O(n)
空间复杂度：O(1)

方法二：快慢指针交换

也可以使用快慢指针，通过交换的方式把非零元素移动到前面：

  • fast 指针负责遍历整个数组
  • slow 指针指向下一个非零元素应该放到的位置

遍历过程中：

  1. 如果 nums[fast] != 0，说明当前元素需要移动到前面
  2. 将 nums[fast] 和 nums[slow] 交换
  3. slow 向后移动一位
  4. 如果 nums[fast] == 0，直接跳过

这种写法和“移除元素”的思路很像，只不过这里不是返回新长度，而是把后面的空位保留为 0。

时间复杂度：O(n)
空间复杂度：O(1)

class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        fast = 0

        while fast < len(nums):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
            fast += 1

        while slow < len(nums):
            nums[slow] = 0
            slow += 1

复杂度分析

方法 时间复杂度 空间复杂度
两次遍历 O(n) O(1)
快慢指针交换 O(n) O(1)

选择建议：

  • 两次遍历思路最直观，先收集非零元素，再把剩余位置补 0
  • 快慢指针交换只需要一次遍历，写法简洁，是本题更常用的解法
