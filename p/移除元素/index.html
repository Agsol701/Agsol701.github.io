移除元素

Apr 04, 2026

题目描述

原题链接：https://leetcode.cn/problems/remove-element/ 给你一个数组 nums 和一个值 val，你需要 原地 移除所有数值等于 val 的元素。元素的顺序可能发生改变。然后返回 nums 中与 val 不同的元素的数量。

假设 nums 中不等于 val 的元素数量为 k，要通过此题，您需要执行以下操作：

更改 nums 数组，使 nums 的前 k 个元素包含不等于 val 的元素。nums 的其余元素和 nums 的大小并不重要。 返回 k。 用户评测：

评测机将使用以下代码测试您的解决方案：

int[] nums = […]; // 输入数组 int val = …; // 要移除的值 int[] expectedNums = […]; // 长度正确的预期答案。 // 它以不等于 val 的值排序。

int k = removeElement(nums, val); // 调用你的实现

assert k == expectedNums.length; sort(nums, 0, k); // 排序 nums 的前 k 个元素 for (int i = 0; i < actualLength; i++) { assert nums[i] == expectedNums[i]; } 如果所有的断言都通过，你的解决方案将会 通过。

示例 1：

输入：nums = [3,2,2,3], val = 3 输出：2, nums = [2,2,,] 解释：你的函数应该返回 k = 2, 并且 nums 中的前两个元素均为 2。 你在返回的 k 个元素之外留下了什么并不重要（因此它们并不计入评测）。 示例 2：

输入：nums = [0,1,2,2,3,0,4,2], val = 2 输出：5, nums = [0,1,4,0,3,,,_] 解释：你的函数应该返回 k = 5，并且 nums 中的前五个元素为 0,0,1,3,4。 注意这五个元素可以任意顺序返回。 你在返回的 k 个元素之外留下了什么并不重要（因此它们并不计入评测）。

提示：

0 <= nums.length <= 100 0 <= nums[i] <= 50 0 <= val <= 100

解题思路

这道题的要求是“原地”移除指定元素，因此不能额外开一个新数组来保存结果。

比较常见的做法是使用双指针，也可以理解为快慢指针：

  • fast 指针负责遍历整个数组，寻找当前元素是否需要保留
  • slow 指针负责指向下一个应该写入的位置

遍历过程如下：

  • 如果 nums[fast] != val，说明这个元素需要保留，就把它放到 slow 指向的位置，然后让 slow 向后移动一位
  • 如果 nums[fast] == val，说明这个元素需要删除，直接跳过即可

当遍历结束后：

  • 数组前 slow 个位置保存的就是所有不等于 val 的元素
  • slow 的值也就是题目要求返回的新长度

这种方法的关键在于：

  • fast 始终向前扫描
  • slow 只在遇到需要保留的元素时才前进

这样就可以在原数组上完成覆盖，不需要额外空间。

时间复杂度：O(n)
空间复杂度：O(1)

from typing import List


class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        fast = slow = 0
        while fast < len(nums):
            print(fast, "|", slow, "|", nums)
            if nums[fast] != val:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1

            fast += 1
        return slow

func removeElement(nums []int, val int) int {
	slow := 0
	fast := 0
	for fast < len(nums) {
		if nums[fast] != val {
			nums[slow] = nums[fast]
			slow++
		}
		fast++
	}
	return slow
}
