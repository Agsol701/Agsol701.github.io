除自身以外数组的乘积

May 30, 2026

题目描述

原题链接：https://leetcode.cn/problems/product-of-array-except-self/

给你一个整数数组 nums，返回数组 answer，其中 answer[i] 等于 nums 中除 nums[i] 之外其余各元素的乘积。

题目数据保证数组 nums 之中任意元素的全部前缀元素和后缀元素的乘积都在 32 位整数范围内。

请不要使用除法，且在 O(n) 时间复杂度内完成此题。

示例 1：

1
2

输入：nums = [1,2,3,4]
输出：[24,12,8,6]

示例 2：

1
2

输入：nums = [-1,1,0,-3,3]
输出：[0,0,9,0,0]

提示：

  • 2 <= nums.length <= 10^5
  • -30 <= nums[i] <= 30
  • 输入保证数组 answer[i] 在 32 位整数范围内

进阶：

你可以在 O(1) 的额外空间复杂度内完成这个题目吗？出于空间复杂度分析的目的，输出数组不被视为额外空间。

解题思路

这道题要求计算每个位置除自身以外所有元素的乘积，并且不能使用除法。

对于下标 i，答案可以拆成两部分：

1

answer[i] = nums[0] * ... * nums[i - 1] * nums[i + 1] * ... * nums[n - 1]

也就是：

1

answer[i] = 左侧所有元素乘积 * 右侧所有元素乘积

因此核心思路是分别统计每个位置左边的乘积和右边的乘积。

方法一：前缀乘积 + 后缀乘积

最直观的做法是分别创建两个数组：

  • left[i] 表示 nums[i] 左侧所有元素的乘积
  • right[i] 表示 nums[i] 右侧所有元素的乘积

对于边界位置：

  • left[0] = 1，因为第一个元素左侧没有元素
  • right[n - 1] = 1，因为最后一个元素右侧没有元素

状态转移：

1
2

left[i] = left[i - 1] * nums[i - 1]
right[i] = right[i + 1] * nums[i + 1]

最后：

1

answer[i] = left[i] * right[i]

具体步骤：

  1. 创建长度为 n 的 left 和 right 数组，并初始化为 1
  2. 从左到右计算每个位置左侧所有元素的乘积
  3. 从右到左计算每个位置右侧所有元素的乘积
  4. 遍历数组，将 left[i] * right[i] 放入答案

时间复杂度：O(n)
空间复杂度：O(n)

方法二：输出数组复用前缀乘积

因为题目说明输出数组不计入额外空间，所以可以直接用 answer 保存前缀乘积，再从右往左维护一个变量 rightProduct 表示当前位置右侧所有元素的乘积。

第一次从左到右遍历：

1

answer[i] = nums[0] * ... * nums[i - 1]

第二次从右到左遍历时，rightProduct 表示：

1

nums[i + 1] * ... * nums[n - 1]

此时把它乘到 answer[i] 上，就能得到除自身以外数组的乘积。

具体步骤：

  1. 创建长度为 n 的 answer 数组，并初始化为 1
  2. 从左到右遍历，用变量 leftProduct 记录当前元素左侧乘积，并写入 answer[i]
  3. 从右到左遍历，用变量 rightProduct 记录当前元素右侧乘积
  4. 每次令 answer[i] *= rightProduct
  5. 更新 rightProduct *= nums[i]

时间复杂度：O(n)
空间复杂度：O(1)，不计算输出数组

class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        left = [1] * n
        right = [1] * n
        answer = [1] * n

        for i in range(1, n):
            left[i] = left[i - 1] * nums[i - 1]

        for i in range(n - 2, -1, -1):
            right[i] = right[i + 1] * nums[i + 1]

        for i in range(n):
            answer[i] = left[i] * right[i]

        return answer

func productExceptSelf(nums []int) []int {
	n := len(nums)
	left := make([]int, n)
	right := make([]int, n)
	answer := make([]int, n)

	for i := 0; i < n; i++ {
		left[i] = 1
		right[i] = 1
	}

	for i := 1; i < n; i++ {
		left[i] = left[i-1] * nums[i-1]
	}

	for i := n - 2; i >= 0; i-- {
		right[i] = right[i+1] * nums[i+1]
	}

	for i := 0; i < n; i++ {
		answer[i] = left[i] * right[i]
	}

	return answer
}

class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        answer = [1] * n
        leftProduct = 1

        for i in range(n):
            answer[i] = leftProduct
            leftProduct *= nums[i]

        rightProduct = 1
        for i in range(n - 1, -1, -1):
            answer[i] *= rightProduct
            rightProduct *= nums[i]

        return answer

func productExceptSelf(nums []int) []int {
	n := len(nums)
	answer := make([]int, n)
	leftProduct := 1

	for i := 0; i < n; i++ {
		answer[i] = leftProduct
		leftProduct *= nums[i]
	}

	rightProduct := 1
	for i := n - 1; i >= 0; i-- {
		answer[i] *= rightProduct
		rightProduct *= nums[i]
	}

	return answer
}

复杂度分析

方法 时间复杂度 空间复杂度
前缀乘积 + 后缀乘积 O(n) O(n)
输出数组复用前缀乘积 O(n) O(1)

选择建议：

  • 前缀乘积 + 后缀乘积思路直观，适合理解乘积拆分过程
  • 输出数组复用前缀乘积可以做到 O(1) 额外空间，是本题推荐解法
  • 本题不能使用除法，前后缀乘积可以自然处理数组中存在 0 的情况
