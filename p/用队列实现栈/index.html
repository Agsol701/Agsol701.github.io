用队列实现栈

Nov 21, 2025

题目描述

原题链接：https://leetcode.cn/problems/implement-stack-using-queues/ 请你仅使用两个队列实现一个后入先出（LIFO）的栈，并支持普通栈的全部四种操作（push、top、pop 和 empty）。

实现 MyStack 类：

  • void push(int x) 将元素 x 压入栈顶。
  • int pop() 移除并返回栈顶元素。
  • int top() 返回栈顶元素。
  • boolean empty() 如果栈是空的，返回 true ；否则，返回 false 。

注意：

  • 你只能使用队列的标准操作 —— 也就是 push to back、peek/pop from front、size 和 is empty 这些操作。
  • 你所使用的语言也许不支持队列。 你可以使用 list （列表）或者 deque（双端队列）来模拟一个队列 , 只要是标准的队列操作即可。

示例：
输入：
[“MyStack”, “push”, “push”, “top”, “pop”, “empty”]. [[], [1], [2], [], [], []]. 输出：
[null, null, null, 2, 2, false].

解释：
MyStack myStack = new MyStack();
myStack.push(1);
myStack.push(2);
myStack.top(); // 返回 2
myStack.pop(); // 返回 2
myStack.empty(); // 返回 False

提示：

  • 1 <= x <= 9
  • 最多调用100 次 push、pop、top 和 empty
  • 每次调用 pop 和 top 都保证栈不为空

进阶：你能否仅用一个队列来实现栈。

解题思路

双队列

准备两个队列，一个用来存储数据，一个用来临时存储数据。每次push的时候，将数据push到临时队列，然后将数据队列中的数据依次push到临时队列，最后将临时队列赋值给数据队列。这样数据队列中的数据顺序就是栈的顺序了。

单队列

逻辑同双队列，只不过push的时候，将数据push到队列，然后将队列中的数据依次push到队列。

class MyStack:

    def __init__(self):
        self.cur = []
        self.temp = []

    def push(self, x: int) -> None:
        self.temp.append(x)
        self.temp.extend(self.cur)
        self.cur, self.temp = self.temp, self.cur
        self.temp.clear()

    def pop(self) -> int:
        res = self.cur[0]
        self.cur = self.cur[1:]
        return res

    def top(self) -> int:
        return self.cur[0]

    def empty(self) -> bool:
        return len(self.cur) == 0


class MyStack1:

    def __init__(self):
        self.cur = []

    def push(self, x: int) -> None:
        cur_len = len(self.cur)  # 取入队前长度
        self.cur.append(x)  # 元素入队
        self.cur.extend(self.cur[:cur_len])  # 将除了最后入队元素拼接到队列后
        self.cur = self.cur[cur_len:]  # 切除入队元素左侧的部分

        self.cur = self.cur[1:]

import collections


class MyStack2:
    """
    leetcode使用 collection.deque()双队列版本,
    """

    def __init__(self):
        self.cur = collections.deque()
        self.temp = collections.deque()

    def push(self, x: int) -> None:
        self.temp.append(x)
        while self.cur:
            self.temp.append(self.cur.popleft())
        self.cur, self.temp = self.temp, self.cur

    def pop(self) -> int:
        return self.cur.popleft()

    def top(self) -> int:
        return self.cur[0]

    def empty(self) -> bool:
        return not self.cur


class MyStack3:
    """
    leetcode使用 collection.deque()双队列版本,
    """

    def __init__(self):
        self.queue = collections.deque()

    def push(self, x: int) -> None:
        n = len(self.queue)
        self.queue.append(x)
        for _ in range(n):
            self.queue.append(self.queue.popleft())

    def pop(self) -> int:
        return self.cur.popleft()

    def top(self) -> int:
        return self.cur[0]

    def empty(self) -> bool:
        return not self.cur

package main

import "fmt"

type MyStack struct {
	cur  []int
	temp []int
}

func Constructor() MyStack {
	return MyStack{}
}

func (this *MyStack) Push(x int) {
	this.temp = append(this.temp, x)
	this.temp = append(this.temp, this.cur...)
	this.cur, this.temp = this.temp, this.cur
	this.temp = this.temp[:0]
}

func (this *MyStack) Pop() int {
	res := this.cur[0]
	this.cur = this.cur[1:len(this.cur)]
	return res
}

func (this *MyStack) Top() int {
	return this.cur[0]
}

func (this *MyStack) Empty() bool {
	return len(this.cur) == 0
}
