下一个更大的元素

Nov 23, 2025

题目描述

nums1 中数字 x 的 下一个更大元素 是指 x 在 nums2 中对应位置 右侧 的 第一个 比 x 大的元素。

给你两个 没有重复元素 的数组 nums1 和 nums2 ，下标从 0 开始计数，其中nums1 是 nums2 的子集。

对于每个 0 <= i < nums1.length ，找出满足 nums1[i] == nums2[j] 的下标 j ，并且在 nums2 确定 nums2[j] 的 下一个更大元素 。如果不存在下一个更大元素，那么本次查询的答案是 -1 。

返回一个长度为 nums1.length 的数组 ans 作为答案，满足 ans[i] 是如上所述的 下一个更大元素 。

示例 1：

输入：nums1 = [4,1,2], nums2 = [1,3,4,2].
输出：[-1,3,-1]
解释：nums1 中每个值的下一个更大元素如下所述：
- 4 ，用加粗斜体标识，nums2 = [1,3,4,2]。不存在下一个更大元素，所以答案是 -1 。
- 1 ，用加粗斜体标识，nums2 = [1,3,4,2]。下一个更大元素是 3 。
- 2 ，用加粗斜体标识，nums2 = [1,3,4,2]。不存在下一个更大元素，所以答案是 -1 。

示例 2：

输入：nums1 = [2,4], nums2 = [1,2,3,4].
输出：[3,-1]
解释：nums1 中每个值的下一个更大元素如下所述：
- 2 ，用加粗斜体标识，nums2 = [1,2,3,4]。下一个更大元素是 3 。
- 4 ，用加粗斜体标识，nums2 = [1,2,3,4]。不存在下一个更大元素，所以答案是 -1 。

提示：

  • 1 <= nums1.length <= nums2.length <= 1000
  • 0 <= nums1[i], nums2[i] <= 104
  • nums1和nums2中所有整数 互不相同
  • nums1 中的所有整数同样出现在 nums2 中

**进阶：**你可以设计一个时间复杂度为 O(nums1.length + nums2.length) 的解决方案吗？

解题思路

两种方法，一种暴力，一种单调栈

方法一：暴力

直接两个循环，先在nums2中找到nums1中元素索引，从这个缩进+1 位置开始内层循环。找到第一个比nums1中元素大的值，如果没有找到，则赋值为-1

方法二：单调栈

from typing import List


class Solution:
    def nextGreaterElement(self, nums1: List[int], nums2: List[int]) -> List[int]:
        """
        方法 1：两边循环直接暴力解
        """
        ans = []
        for i in range(len(nums1)):
            flag = True
            cur_ind = nums2.index(nums1[i])
            for j in range(cur_ind + 1, len(nums2)):
                if nums2[j] > nums1[i]:
                    ans.append(nums2[j])
                    flag = False
                    break
            if flag:
                ans.append(-1)
        return ans


nums1 = [4, 1, 2]
nums2 = [1, 3, 4, 2]
print(Solution().nextGreaterElement(nums1, nums2))

复杂度分析

  • 时间复杂度：O(mn)，其中 m 是 nums1 的长度，n 是 nums2 的长度。
  • 空间复杂度：O(1)。

class Solution1:
    def nextGreaterElement(self, nums1: List[int], nums2: List[int]) -> List[int]:
        """
        方法 1：单调栈 + 哈希
        主要逻辑在于栈的操作
            栈顶元素比当前数小 → 当前数就是它的 next greater
            弹出栈顶，把答案记录下来
            持续弹出，比当前小的全部都处理完
        对于单调栈的解释：
            栈底元素一定大于上方元素，因为如果
        """
        stack = []
        elem_dict = {}
        # 操作栈，构建哈希表
        for nums in nums2:
            while stack and nums > stack[-1]:
                elem_dict[stack.pop()] = nums
            stack.append(nums)
            print(stack)

        # 栈内剩余的元素，说明都是没有下一个最大
        for nums in stack:
            elem_dict[nums] = -1

        return [elem_dict[nums] for nums in nums1]

func nextGreaterElement(nums1 []int, nums2 []int) []int {
	ans := make([]int, len(nums1))
	for i := 0; i < len(nums1); i++ {
		flag := false
		j := 0
		for j < len(nums2) && nums1[i] != nums2[j] {
			j++
		}
		k := j + 1
		for k < len(nums2) {
			if nums2[k] > nums1[i] {
				ans[i] = nums2[k]
				flag = true
				break
			}
			k++
		}
		if !flag {
			ans[i] = -1
		}
		fmt.Println(ans)
	}
	return ans
}


func nextGreaterElement1(nums1 []int, nums2 []int) []int {
	stack := []int{}
	mp := map[int]int{}
	ans := make([]int, len(nums1))
	for i := 0; i < len(nums2); i++ {
		for len(stack) > 0 && nums2[i] > stack[len(stack)-1] {
			mp[stack[len(stack)-1]] = nums2[i]
			stack = stack[:len(stack)-1]
		}
		stack = append(stack, nums2[i])
	}
	for j := 0; j < len(stack); j++ {
		mp[stack[j]] = -1
	}
	for k := 0; k < len(nums1); k++ {
		ans[k] = mp[nums1[k]]
	}
	return ans
}
