四数相加 II

Apr 17, 2026

题目描述

原题链接：https://leetcode.cn/problems/4sum-ii/

给你四个整数数组 nums1、nums2、nums3 和 nums4，数组长度都是 n，请你计算有多少个元组 (i, j, k, l) 能满足：

  • 0 <= i, j, k, l < n
  • nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0

示例 1：

3
4

6

输入：nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
输出：2
解释：
两个元组如下：
1. (0, 0, 0, 1) -> nums1[0] + nums2[0] + nums3[0] + nums4[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> nums1[1] + nums2[1] + nums3[0] + nums4[0] = 2 + (-1) + (-1) + 0 = 0

示例 2：

1
2

输入：nums1 = [0], nums2 = [0], nums3 = [0], nums4 = [0]
输出：1

提示：

  • n == nums1.length == nums2.length == nums3.length == nums4.length
  • 1 <= n <= 200
  • -2²⁸ <= nums1[i], nums2[i], nums3[i], nums4[i] <= 2²⁸

解题思路

核心目标：从四个数组中各取一个数，使它们的和为 0，统计满足条件的元组个数。

方法一：暴力枚举

最直观的思路，使用四层循环枚举所有组合：

  1. 四层循环分别遍历 nums1、nums2、nums3、nums4
  2. 如果四个数之和为 0，计数加 1

时间复杂度：O(n⁴)，四层循环 空间复杂度：O(1)

方法二：哈希表分组

将四个数组分成两组，用哈希表存储一组的和，再用另一组去查找互补值：

  1. 遍历 nums1 和 nums2 的所有组合，将 nums1[i] + nums2[j] 的值及出现次数存入哈希表
  2. 遍历 nums3 和 nums4 的所有组合，查找 -(nums3[k] + nums4[l]) 在哈希表中出现的次数
  3. 将所有匹配次数累加即为答案

时间复杂度：O(n²)，两次两两组合遍历 空间复杂度：O(n²)，哈希表最多存储 n² 个和

class Solution:
    def fourSumCount(self, nums1: List[int], nums2: List[int], nums3: List[int], nums4: List[int]) -> int:
        count = 0
        for a in nums1:
            for b in nums2:
                for c in nums3:
                    for d in nums4:
                        if a + b + c + d == 0:
                            count += 1
        return count

func fourSumCount(nums1 []int, nums2 []int, nums3 []int, nums4 []int) int {
	count := 0
	for _, a := range nums1 {
		for _, b := range nums2 {
			for _, c := range nums3 {
				for _, d := range nums4 {
					if a+b+c+d == 0 {
						count++
					}
				}
			}
		}
	}
	return count
}

class Solution:
    def fourSumCount(self, nums1: List[int], nums2: List[int], nums3: List[int], nums4: List[int]) -> int:
        sum12 = {}
        for i in nums1:
            for j in nums2:
                sum12[i + j] = sum12.get(i + j, 0) + 1

        count = 0
        for k in nums3:
            for l in nums4:
                count += sum12.get(-(k + l), 0)
        return count

func fourSumCount(nums1 []int, nums2 []int, nums3 []int, nums4 []int) int {
	sum12 := make(map[int]int)
	for _, a := range nums1 {
		for _, b := range nums2 {
			//Go 的 map 访问不存在的 key 时，会自动返回值类型的零值（zero value），不会报错。
			sum12[a+b]++
		}
	}

	count := 0
	for _, c := range nums3 {
		for _, d := range nums4 {
			count += sum12[-(c + d)]
		}
	}
	return count
}

复杂度分析

方法 时间复杂度 空间复杂度
暴力枚举 O(n⁴) O(1)
哈希表分组 O(n²) O(n²)

选择建议：

  • 暴力枚举仅适用于 n 极小的情况，n=200 时一定会超时
  • 哈希表分组是本题的最优解法，将 O(n⁴) 降到 O(n²)，用空间换时间
