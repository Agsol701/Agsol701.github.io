无重复字符的最长子串

May 28, 2026

题目描述

原题链接：https://leetcode.cn/problems/longest-substring-without-repeating-characters/

给定一个字符串 s，请你找出其中不含有重复字符的最长子串的长度。

示例 1：

1
2
3

输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，所以其长度为 3。

示例 2：

1
2
3

输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 "b"，所以其长度为 1。

示例 3：

1
2
3
4

输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，所以其长度为 3。
请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串。

提示：

  • 0 <= s.length <= 5 * 10^4
  • s 由英文字母、数字、符号和空格组成

解题思路

这道题的核心是维护一个没有重复字符的连续窗口。

因为子串必须是连续的，所以可以使用滑动窗口。先明确几个变量的含义：

  • left：当前窗口的左边界
  • right：当前窗口的右边界，也是当前正在遍历的位置
  • ch：当前遍历到的字符，也就是 s[right]
  • lastInd：哈希表，记录每个字符最近一次出现的位置
  • maxLength：遍历过程中出现过的最长无重复子串长度

为什么是 lastInd[ch] + 1

当 ch 之前出现过，并且上一次出现的位置还在当前窗口内时，说明窗口里出现了重复字符。

例如 s = "abcabcbb"：

1
2

下标： 0 1 2 3 4 5 6 7
字符： a b c a b c b b

当遍历到下标 3 的 a 时，当前窗口是：

1

[0, 3] => "abca"

这里有两个 a：一个在下标 0，一个在下标 3。为了让窗口重新变成无重复字符窗口，必须把左边界移动到上一个 a 的后面：

1
2
3

left = lastInd['a'] + 1
left = 0 + 1
left = 1

移动后窗口变成：

1

[1, 3] => "bca"

所以要加 1，是因为上一次出现的那个字符本身也要被排除掉。如果只移动到 lastInd[ch]，重复字符还会留在窗口里。

为什么要判断上次出现位置是否在窗口中

更直观的写法是：

1
2

if ch in lastInd and lastInd[ch] >= left:
    left = lastInd[ch] + 1

ch in lastInd 只能说明这个字符之前出现过，但不能说明它还在当前窗口中。只有 lastInd[ch] >= left，才说明这个字符上一次出现的位置仍然在当前窗口 [left, right] 里，此时才需要移动 left。

以 s = "abba" 为例：

1
2

下标： 0 1 2 3
字符： a b b a

遍历到下标 2 的第二个 b 时：

1
2
3
4

当前窗口：[0, 2] => "abb"
'b' 上一次出现在下标 1
left = lastInd['b'] + 1 = 2
移动后窗口：[2, 2] => "b"

此时 left 已经是 2，表示窗口左边界已经移动到了下标 2。

继续遍历到下标 3 的 a 时：

1
2

'a' 上一次出现在下标 0
当前窗口：[2, 2] => "b"

下标 0 的 a 已经不在当前窗口里了，所以它不会造成重复。

如果只判断 a in lastInd，然后直接写：

1

left = lastInd['a'] + 1 = 0 + 1 = 1

left 会从 2 回退到 1，窗口变成：

1

[1, 3] => "bba"

这个窗口里有两个 b，已经不是合法的无重复子串。

正确判断应该是：

1
2
3

lastInd['a'] = 0
left = 2
lastInd['a'] >= left  // 0 >= 2，不成立

这说明上一次的 a 已经不在当前窗口中，不需要移动 left。

窗口保持为：

1

[2, 3] => "ba"

这是合法的无重复子串。

为什么每次都要计算 maxLength

你的代码里是先处理 s[right]，再执行 right += 1。所以计算长度时，当前窗口实际是左闭右开区间 [left, right)，长度是：

1

right - left

每次处理完当前字符后，窗口 [left, right) 都是一个合法的无重复窗口，所以都可以用它来更新最长长度：

1

maxLength = max(maxLength, right - left)

不能只在 ch not in lastInd 时更新。因为 ch in lastInd 只表示这个字符以前出现过，不代表它一定在当前窗口里。

例如 s = "tmmzuxt"：

1
2

下标： 0 1 2 3 4 5 6
字符： t m m z u x t

遍历到最后一个 t 时：

1
2
3

right = 6，ch = 't'
lastInd['t'] = 0
当前 left = 2

虽然 t 之前出现过，但上一次的 t 在下标 0，已经不在当前窗口 [2, 5] 里了。所以当前窗口可以继续扩展成：

1

[2, 6] => "mzuxt"

长度是 5，这正是一个新的最长无重复子串。如果只在 ch not in lastInd 时计算 maxLength，这里就会漏掉答案。

为什么每次都要更新 lastInd[s[right]] = right

lastInd 记录的是每个字符“最近一次”出现的位置，不是“第一次”出现的位置。

每次遍历到一个字符，都要把它的位置更新成当前下标。这样后面再次遇到这个字符时，才能用最近的位置判断它是否还在当前窗口中。

例如 s = "abba"：

1
2

下标： 0 1 2 3
字符： a b b a

遍历到第一个 b 时：

1

lastInd['b'] = 1

遍历到第二个 b 时，处理完重复后，必须更新为：

1

lastInd['b'] = 2

如果不更新，后面再遇到 b 时，程序还会以为最近的 b 在下标 1，这就是过期信息，会导致窗口判断不准确。

因此推荐顺序是：

1
2
3
4

先根据 lastInd 判断是否需要移动 left
再更新 lastInd[s[right]] = right
然后 right += 1
最后用当前合法窗口更新 maxLength

时间复杂度：O(n)
空间复杂度：O(m)，其中 m 是字符集大小

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        maxLength = 0
        lastInd = {}
        left, right = 0, 0

        while right < len(s):
            if s[right] in lastInd and lastInd[s[right]] >= left:
                left = lastInd[s[right]] + 1

            lastInd[s[right]] = right
            right += 1
            maxLength = max(maxLength, right - left)

        return maxLength

func lengthOfLongestSubstring(s string) int {
	lastIndex := make(map[byte]int)
	left := 0
	res := 0

	for right := 0; right < len(s); right++ {
		ch := s[right]
		if index, ok := lastIndex[ch]; ok && index >= left {
			left = index + 1
		}

		lastIndex[ch] = right
		res = max(res, right-left+1)
	}

	return res
}

func max(a int, b int) int {
	if a > b {
		return a
	}
	return b
}

方法二：滑动窗口 + while

这个写法不记录字符上一次出现的位置，而是维护一个窗口内的字符集合。

当 s[right] 已经在集合中时，说明当前窗口有重复字符，就不断移动 left，并从集合中删除 s[left]，直到窗口中不再包含 s[right]。

然后再把 s[right] 加入集合，并更新答案。

这种写法更贴近滑动窗口的基本模板：

  1. 右指针不断扩大窗口
  2. 当窗口不满足条件时，左指针不断收缩窗口
  3. 每次窗口合法后更新答案

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        window = set()
        left = 0
        res = 0

        for right in range(len(s)):
            while s[right] in window:
                window.remove(s[left])
                left += 1

            window.add(s[right])
            res = max(res, right - left + 1)

        return res

func lengthOfLongestSubstring(s string) int {
	window := make(map[byte]bool)
	left := 0
	res := 0

	for right := 0; right < len(s); right++ {
		for window[s[right]] {
			delete(window, s[left])
			left++
		}

		window[s[right]] = true
		res = max(res, right-left+1)
	}

	return res
}

func max(a int, b int) int {
	if a > b {
		return a
	}
	return b
}

复杂度分析

方法 时间复杂度 空间复杂度
滑动窗口 O(n) O(m)
滑动窗口 + while O(n) O(m)

选择建议：

  • 滑动窗口是本题的推荐解法，可以保证每个字符最多被左右指针访问常数次
  • 使用哈希表记录字符最近一次出现的位置，可以直接跳过重复字符之前的无效区间
  • while 写法更容易套用滑动窗口模板，适合初学时理解窗口的扩张和收缩过程
