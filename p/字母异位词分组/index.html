字母异位词分组

May 26, 2026

题目描述

原题链接：https://leetcode.cn/problems/group-anagrams/

给你一个字符串数组 strs，请你将字母异位词组合在一起。可以按任意顺序返回结果列表。

字母异位词是由重新排列源单词的所有字母得到的一个新单词。

示例 1：

1
2

输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]

示例 2：

1
2

输入：strs = [""]
输出：[[""]]

示例 3：

1
2

输入：strs = ["a"]
输出：[["a"]]

提示：

  • 1 <= strs.length <= 10^4
  • 0 <= strs[i].length <= 100
  • strs[i] 仅包含小写字母

解题思路

核心目标：把所有互为字母异位词的字符串分到同一组。

判断两个字符串是否为字母异位词，本质上是判断它们包含的字符及每个字符出现次数是否相同。因此可以为每个字符串构造一个“特征值”，互为字母异位词的字符串会得到相同的特征值，然后用哈希表按照特征值分组。

方法一：排序作为 key

如果两个字符串互为字母异位词，那么将它们的字符排序之后，得到的字符串一定相同。

例如：

  • "eat" 排序后是 "aet"
  • "tea" 排序后是 "aet"
  • "ate" 排序后是 "aet"

因此可以把排序后的字符串作为哈希表的 key：

  1. 遍历数组中的每个字符串 s
  2. 对 s 的字符排序，得到 key
  3. 将原字符串 s 加入 hashMap[key] 对应的列表
  4. 遍历结束后，哈希表中的所有 value 就是答案

时间复杂度：O(n * klogk)，其中 n 是字符串数量，k 是字符串最大长度
空间复杂度：O(n * k)，哈希表需要存储所有字符串

方法二：计数数组作为 key

由于题目说明字符串只包含小写字母，也可以用长度为 26 的数组统计每个字母出现次数，并将这个计数结果作为 key。

例如：

  • "eat" 的字符频次和 "tea" 相同
  • "tan" 的字符频次和 "nat" 相同

做法如下：

  1. 遍历每个字符串 s
  2. 使用长度为 26 的数组统计 s 中每个字符出现的次数
  3. 将计数数组转换成可作为哈希表 key 的形式
  4. 将 s 加入对应分组

这种方法避免了排序，单个字符串只需要线性扫描。

时间复杂度：O(n * k)
空间复杂度：O(n * k)，哈希表需要存储所有字符串；计数数组长度固定为 26

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        hashMap = {}

        for s in strs:
            key = ''.join(sorted(s))
            if key not in hashMap:
                hashMap[key] = []
            hashMap[key].append(s)

        return list(hashMap.values())

func groupAnagrams(strs []string) [][]string {
	hashMap := make(map[string][]string)

	for _, s := range strs {
		chars := []byte(s)
		sort.Slice(chars, func(i, j int) bool {
			return chars[i] < chars[j]
		})
		key := string(chars)
		hashMap[key] = append(hashMap[key], s)
	}

	res := make([][]string, 0, len(hashMap))
	for _, group := range hashMap {
		res = append(res, group)
	}
	return res
}

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        hashMap = {}

        for s in strs:
            count = [0] * 26
            for ch in s:
                count[ord(ch) - ord('a')] += 1

            key = tuple(count)
            if key not in hashMap:
                hashMap[key] = []
            hashMap[key].append(s)

        return list(hashMap.values())

func groupAnagrams(strs []string) [][]string {
	hashMap := make(map[[26]int][]string)

	for _, s := range strs {
		var count [26]int
		for i := 0; i < len(s); i++ {
			count[s[i]-'a']++
		}
		hashMap[count] = append(hashMap[count], s)
	}

	res := make([][]string, 0, len(hashMap))
	for _, group := range hashMap {
		res = append(res, group)
	}
	return res
}

复杂度分析

方法 时间复杂度 空间复杂度
排序作为 key O(n * klogk) O(n * k)
计数数组作为 key O(n * k) O(n * k)

选择建议：

  • 排序作为 key 思路直观，代码简单，适合快速写出正确解法
  • 计数数组作为 key 利用了只包含小写字母的条件，时间复杂度更优，是本题的推荐解法
