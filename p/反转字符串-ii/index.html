反转字符串 II

Apr 21, 2026

题目描述

原题链接：https://leetcode.cn/problems/reverse-string-ii/description/

给定一个字符串 s 和一个整数 k，从字符串开头算起，每计数至 2k 个字符，就反转这 2k 个字符中的前 k 个字符。

  • 如果剩余字符少于 k 个，则将剩余字符全部反转。
  • 如果剩余字符小于 2k 但大于或等于 k 个，则反转前 k 个字符，其余字符保持原样。

示例 1：

1
2

输入：s = "abcdefg", k = 2
输出："bacdfeg"

示例 2：

1
2

输入：s = "abcd", k = 2
输出："bacd"

提示：

  • 1 <= s.length <= 10^4
  • s 仅由小写英文组成
  • 1 <= k <= 10^4

解题思路

这道题的规则可以直接按题意模拟。

我们每次处理一段长度为 2k 的区间，但真正需要反转的只有前 k 个字符，所以可以让下标每次前进 2k：

  • 当前区间起点为 i
  • 反转区间左边界为 i
  • 反转区间右边界为 min(i + k - 1, len(s) - 1)

这样无论剩余字符是否不足 k，都可以通过 min 自动兼容。

为了便于原地交换，先把字符串转成字符数组，然后使用双指针反转指定区间：

  • left 指向区间开头
  • right 指向区间结尾
  • 每次交换后向中间收缩

时间复杂度是 O(n)，因为每个字符最多被访问常数次；空间复杂度是 O(n)，主要来自 Go / Python 中把字符串转为可修改数组。

时间复杂度：O(n)
空间复杂度：O(n)

class Solution:
    def reverseStr(self, s: str, k: int) -> str:
        chars = list(s)

        for i in range(0, len(chars), 2 * k):
            left = i
            right = min(i + k - 1, len(chars) - 1)

            while left < right:
                chars[left], chars[right] = chars[right], chars[left]
                left += 1
                right -= 1

        return "".join(chars)

func reverseStr(s string, k int) string {
	chars := []byte(s)

	for i := 0; i < len(chars); i += 2 * k {
		left := i
		right := min(i+k-1, len(chars)-1)

		for left < right {
			chars[left], chars[right] = chars[right], chars[left]
			left++
			right--
		}
	}

	return string(chars)
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}
