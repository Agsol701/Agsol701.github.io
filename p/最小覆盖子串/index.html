最小覆盖子串

May 30, 2026

题目描述

原题链接：https://leetcode.cn/problems/minimum-window-substring/

给你一个字符串 s、一个字符串 t。返回 s 中涵盖 t 所有字符的最小子串。

如果 s 中不存在涵盖 t 所有字符的子串，则返回空字符串 ""。

注意：

  • 对于 t 中重复字符，窗口中也需要包含对应数量的字符
  • 如果 s 中存在这样的子串，保证它是唯一的答案

示例 1：

1
2
3

输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

示例 2：

1
2
3

输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。

示例 3：

1
2
3

输入：s = "a", t = "aa"
输出：""
解释：t 中两个字符 'a' 均应包含在 s 的子串中，因此没有符合条件的子字符串，返回空字符串。

提示：

  • m == s.length
  • n == t.length
  • 1 <= m, n <= 10^5
  • s 和 t 由英文字母组成

解题思路

这道题要求在 s 中找到一个最短的连续子串，并且这个子串要覆盖 t 中的所有字符。

因为子串必须是连续的，而且我们需要不断判断当前区间是否已经满足要求，所以可以使用滑动窗口 + 哈希表。

核心变量：

  • need：记录 t 中每个字符需要出现的次数
  • window：记录当前窗口中每个字符已经出现的次数
  • left：窗口左边界
  • right：窗口右边界
  • valid_count：当前窗口中有多少种字符已经满足 need 的数量要求
  • start 和 minLen：记录当前找到的最小覆盖子串起点和长度

为什么不能只判断字符是否出现

t 中可能有重复字符，例如：

1
2

s = "aaab"
t = "aab"

答案应该是：

1

"aab"

这里 t 需要两个 a 和一个 b。如果只判断窗口中是否出现过 a 和 b，那么窗口 "ab" 会被误判为满足条件，但它只有一个 a，数量不够。

因此，必须用哈希表记录每个字符的需求次数：

1
2

need['a'] = 2
need['b'] = 1

只有当窗口中某个字符的数量刚好达到需求数量时，才说明这个字符已经满足要求。

为什么使用 valid_count

每次判断窗口是否覆盖 t，如果都遍历整个 need 哈希表，会产生额外开销。

可以用 valid_count 记录当前有多少种字符已经满足要求：

1

window[ch] == need[ch]

当 valid_count == len(need) 时，说明 need 中所有字符都已经满足，当前窗口就是一个可行窗口。

注意：valid_count 统计的是“满足要求的字符种类数”，不是字符总数。

例如：

1
2

t = "AABC"
need = {'A': 2, 'B': 1, 'C': 1}

只有当窗口中：

1
2
3

A 的数量 >= 2
B 的数量 >= 1
C 的数量 >= 1

并且这 3 种字符都满足时，valid_count 才等于 3。

窗口如何扩展和收缩

整体流程分为两步：

  1. 右指针 right 向右移动，不断把字符加入窗口
  2. 当窗口已经覆盖 t 时，左指针 left 向右移动，尝试缩小窗口

扩展窗口时：

  • 如果 s[right] 是 t 中需要的字符，就更新 window
  • 如果更新后 window[ch] == need[ch]，说明这个字符刚好满足要求，valid_count += 1

收缩窗口时：

  • 先用当前窗口更新最小答案
  • 再移除 s[left]
  • 如果移除前这个字符正好满足要求，那么移除后它就不满足了，valid_count -= 1

为什么收缩时先更新答案

当 valid_count == len(need) 时，说明当前窗口已经是一个合法窗口。

此时需要先记录答案，然后再移动 left 尝试缩小窗口：

1

s = "ADOBECODEBANC", t = "ABC"

当窗口第一次覆盖 ABC 时，可能是：

1

"ADOBEC"

它虽然不是最短答案，但已经是一个合法答案，需要先记录下来。之后继续移动 left，如果窗口仍然合法，就继续更新更短答案；如果移除某个关键字符后不合法，再停止收缩，继续扩展右边界。

时间复杂度：O(m + n)，其中 m 是 s 的长度，n 是 t 的长度。每个字符最多被左右指针各访问一次。
空间复杂度：O(k)，其中 k 是字符集大小。

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need = {}
        for ch in t:
            need[ch] = need.get(ch, 0) + 1

        window = {}
        left, right = 0, 0
        valid_count = 0
        start, minLen = 0, float('inf')

        while right < len(s):
            ch = s[right]
            window[ch] = window.get(ch, 0) + 1

            if ch in need and window[ch] == need[ch]:
                valid_count += 1

            while valid_count == len(need):
                if right - left + 1 < minLen:
                    start = left
                    minLen = right - left + 1

                remove = s[left]

                if remove in need and window[remove] == need[remove]:
                    valid_count -= 1

                window[remove] -= 1
                left += 1

            right += 1

        return "" if minLen == float('inf') else s[start:start + minLen]

func minWindow(s string, t string) string {
	need := make(map[byte]int)
	for i := 0; i < len(t); i++ {
		need[t[i]]++
	}

	window := make(map[byte]int)
	left, right := 0, 0
	validCount := 0
	start, minLen := 0, len(s)+1

	for right < len(s) {
		ch := s[right]
		window[ch]++

		if _, ok := need[ch]; ok && window[ch] == need[ch] {
			validCount++
		}

		for validCount == len(need) {
			if right-left+1 < minLen {
				start = left
				minLen = right - left + 1
			}

			remove := s[left]

			if _, ok := need[remove]; ok && window[remove] == need[remove] {
				validCount--
			}

			window[remove]--
			left++
		}

		right++
	}

	if minLen == len(s)+1 {
		return ""
	}
	return s[start : start+minLen]
}
