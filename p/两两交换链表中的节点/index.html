两两交换链表中的节点

Apr 11, 2026

题目描述

原题链接：https://leetcode.cn/problems/swap-nodes-in-pairs/

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。

你必须在不修改节点内部的值的情况下完成本题，也就是说，只能进行节点交换。

示例 1：

1
2

输入：head = [1,2,3,4]
输出：[2,1,4,3]

示例 2：

1
2

输入：head = []
输出：[]

示例 3：

1
2

输入：head = [1]
输出：[1]

提示：

  • 链表中节点的数目在范围 [0, 100] 内
  • 0 <= Node.val <= 100

解题思路

这道题要求不能修改节点的值，只能交换节点本身，因此需要调整链表指针。

比较稳妥的做法是使用虚拟头节点 dummy。

为什么需要虚拟头节点？

因为链表的头两个节点也可能发生交换。例如：

1

1 -> 2 -> 3 -> 4

交换后会变成：

1

2 -> 1 -> 4 -> 3

此时新的头节点不再是原来的 head，而是原来的第二个节点。使用 dummy 可以统一处理头节点变化，避免额外特判。

每次处理一组相邻节点：

1

prev -> first -> second -> next

交换后应该变成：

1

prev -> second -> first -> next

对应的指针调整顺序是：

  1. first.next = second.next
  2. second.next = first
  3. prev.next = second
  4. prev = first，移动到下一组前一个节点

循环条件是 prev.next != nil 且 prev.next.next != nil，因为只有至少两个节点时才需要交换。

时间复杂度：O(n)
空间复杂度：O(1)

from typing import Optional


class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        prev = dummy

        while prev.next and prev.next.next:
            first = prev.next
            second = prev.next.next

            first.next = second.next
            second.next = first
            prev.next = second

            prev = first

        return dummy.next

type ListNode struct {
	Val  int
	Next *ListNode
}

func swapPairs(head *ListNode) *ListNode {
	dummy := &ListNode{Next: head}
	prev := dummy

	for prev.Next != nil && prev.Next.Next != nil {
		first := prev.Next
		second := prev.Next.Next

		first.Next = second.Next
		second.Next = first
		prev.Next = second

		prev = first
	}

	return dummy.Next
}
