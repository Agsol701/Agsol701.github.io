反转字符串

Apr 20, 2026

题目描述

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 s 的形式给出。

不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

示例

示例 1:

1
2

输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]

示例 2:

1
2

输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]

约束条件

  • 1 <= s.length <= 10^5
  • s[i] 都是 ASCII 码表中的可打印字符

解法

方法一：双指针（推荐）

使用两个指针分别指向字符串的开始和末尾，不断交换两个指针指向的字符，并向中间移动。

时间复杂度: O(n)
空间复杂度: O(1)

def reverseString(s: list[str]) -> None:
    """
    Do not return anything, modify s in-place instead.
    """
    left, right = 0, len(s) - 1
    
    while left < right:
        # 交换
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1

func reverseString(s []byte) {
    left, right := 0, len(s)-1
    
    for left < right {
        s[left], s[right] = s[right], s[left]
        left++
        right--
    }
}

解题要点

  1. 原地修改: 不能额外分配空间，必须在输入数组上进行修改
  2. 双指针技巧: 利用对称性，从两端向中间靠拢
  3. 终止条件: 当 left >= right 时停止，因为中间的元素或已交换完毕

复杂度分析

指标 复杂度
时间复杂度 O(n)
空间复杂度 O(1)

其中 n 是字符串的长度。
