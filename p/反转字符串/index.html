反转字符串

Apr 20, 2026

题目描述

原题链接：https://leetcode.cn/problems/reverse-string/

编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 s 的形式给出。

不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

示例 1：

1
2

输入：s = ["h","e","l","l","o"]
输出：["o","l","l","e","h"]

示例 2：

1
2

输入：s = ["H","a","n","n","a","h"]
输出：["h","a","n","n","a","H"]

提示：

  • 1 <= s.length <= 10^5
  • s[i] 都是 ASCII 码表中的可打印字符

解题思路

这道题的核心要求是原地反转字符数组，因此最直接的做法就是使用双指针。

定义两个指针：

  • left 指向数组开头
  • right 指向数组结尾

当 left < right 时，交换两个位置的字符，然后让：

  • left += 1
  • right -= 1

直到两个指针相遇或交错为止，整个数组就完成了原地反转。

这种做法只遍历了数组的一半，效率很高。

时间复杂度：O(n)
空间复杂度：O(1)

from typing import List


class Solution:
    def reverseString(self, s: List[str]) -> None:
        """
        Do not return anything, modify s in-place instead.
        """
        left, right = 0, len(s) - 1

        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1

func reverseString(s []byte) {
	left, right := 0, len(s)-1

	for left < right {
		s[left], s[right] = s[right], s[left]
		left++
		right--
	}
}
