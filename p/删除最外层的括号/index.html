删除最外层的括号

Nov 29, 2025

题目描述

有效括号字符串为空 ""、"(" + A + ")" 或 A + B ，其中 A 和 B 都是有效的括号字符串，+ 代表字符串的连接。

  • 例如，""，"()"，"(())()" 和 "(()(()))" 都是有效的括号字符串。

如果有效字符串 s 非空，且不存在将其拆分为 s = A + B 的方法，我们称其为原语（primitive），其中 A 和 B 都是非空有效括号字符串。

给出一个非空有效字符串 s，考虑将其进行原语化分解，使得：s = P_1 + P_2 + ... + P_k，其中 P_i 是有效括号字符串原语。

对 s 进行原语化分解，删除分解中每个原语字符串的最外层括号，返回 s 。

示例 1：

1
2
3
4
5

输入：s = "(()())(())"
输出："()()()"
解释：
输入字符串为 "(()())(())"，原语化分解得到 "(()())" + "(())"，
删除每个部分中的最外层括号后得到 "()()" + "()" = "()()()"。

示例 2：

输入：s = "(()())(())(()(()))"
输出："()()()()(())"
解释：
输入字符串为 "(()())(())(()(()))"，原语化分解得到 "(()())" + "(())" + "(()(()))"，
删除每个部分中的最外层括号后得到 "()()" + "()" + "()(())" = "()()()()(())"。

示例 3：

1
2
3
4
5

输入：s = "()()"
输出：""
解释：
输入字符串为 "()()"，原语化分解得到 "()" + "()"，
删除每个部分中的最外层括号后得到 "" + "" = ""。

提示：

  • 1 <= s.length <= 105
  • s[i] 为 '(' 或 ')'
  • s 是一个有效括号字符串

class Solution:
    def removeOuterParentheses(self, s: str) -> str:
        """
        自己的算法，比较低级
        :param s:
        :return:
        """
        stack = []
        temp = []
        res = []
        for bracket in s:
            if bracket == '(':
                stack.append(bracket)
                temp.append(bracket)
            elif bracket == ')':
                temp.append(bracket)
                stack.pop()
                if not stack:
                    res.append(''.join(temp[1:len(temp) - 1]))
                    temp.clear()

        return ''.join(res)


class Solution1:
    def removeOuterParentheses(self, s: str) -> str:
        """
        leetcode栈算法，几个 if 的顺序比较关键
        遇到）先出栈，再判断栈是否为空，
            不为空的话，说明栈中是最外层的括号，需要将当前括号放入 res
            如果为空，说明是最外层的括号，无需操作。
        如果第一个 if 写的是（ 入栈，那么当出现（（（）））则会导致结果错误。
        :param s:
        :return:
        """
        stack = []
        res = ""
        for c in s:
            if c == ")":
                stack.pop()
            if stack:
                res += c
            if c == "(":
                stack.append(c)
        return res


class Solution2:
    def removeOuterParentheses(self, s: str) -> str:
        """
        leetcode计数算法，
        与栈是同样的逻辑，只不过用一个计数单位来表示len(stack)
        剩下了内存空间
        """
        res = ""
        level = 0
        for c in s:
            if c == ")":
                level -= 1
            if level:
                res += c
            if c == "(":
                level += 1
        return res

package main

func removeOuterParentheses(s string) string {
	res := ""
	stack := []rune{}
	for _, ch := range s {
		if ch == ')' {
			stack = stack[:len(stack)-1]
		}
		if len(stack) > 0 {
			res += string(ch)
		}
		if ch == '(' {
			stack = append(stack, ch)
		}
	}
	return res
}

func removeOuterParentheses(s string) string {
	res := ""
	counter := 0
	for _, ch := range s {
		if ch == ')' {
			counter--
		}
		if counter > 0 {
			res += string(ch)
		}
		if ch == '(' {
			counter++
		}
	}
	return res
}
