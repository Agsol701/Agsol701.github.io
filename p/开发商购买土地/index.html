开发商购买土地

Apr 08, 2026

题目描述

题目链接（KamaCoder）：https://kamacoder.com/problempage.php?pid=1044

给你一个二维数组 grid，表示一个城市区域的土地价值。其中 grid[i][j] 表示第 i 行第 j 列区块的价值。

这个城市区域被划分成了若干个连续的区块，目前有两家开发公司，A 公司和 B 公司，希望购买这个城市区域的土地。

现在，需要将这个城市区域的所有区块分配给 A 公司和 B 公司。

然而，由于城市规划的限制，只允许将区域按横向或纵向划分成两个子区域，而且每个子区域都必须包含一个或多个区块。为了确保公平竞争，你需要找到一种分配方式，使得 A 公司和 B 公司各自的子区域内的土地总价值之差最小。

注意：区块不可再分。

请你将整个区域按横向或纵向切分成两个非空子区域，并返回这两个子区域土地总价值差的最小值。

输入示例：

1
2
3
4
5

grid = [
  [1, 2, 3],
  [2, 1, 3],
  [1, 2, 3]
]

输出示例：

1

0

提示信息：

如果将区域按照如下方式划分：

1
2
3

1 2 | 3
2 1 | 3
1 2 | 3

两个子区域内土地总价值之间的最小差距可以达到 0。

提示：

  • 1 <= len(grid), len(grid[0]) <= 100
  • len(grid) 和 len(grid[0]) 不同时为 1

解题思路

这道题的切分方式只有两种：

  • 横向切一刀，把矩阵分成上下两个部分
  • 纵向切一刀，把矩阵分成左右两个部分

因此不需要考虑更复杂的划分情况，只要把所有可能的横切线和竖切线都枚举一遍即可。

具体做法：

  1. 先计算整个矩阵的元素总和 total
  2. 枚举横向切分
    • 用 cur 维护上半部分的元素和
    • 下半部分的元素和就是 total - cur
    • 当前差值为 abs(total - 2 * cur)
  3. 枚举纵向切分
    • 用 cur 维护左半部分的元素和
    • 右半部分的元素和就是 total - cur
    • 当前差值同样为 abs(total - 2 * cur)
  4. 取所有切分方式中的最小值

为什么差值可以写成 abs(total - 2 * cur)？

如果当前一部分的和为 cur，另一部分的和为 total - cur，那么两部分的差值为：

1

abs(cur - (total - cur)) = abs(total - 2 * cur)

时间复杂度：O(m * n)
空间复杂度：O(1)

from typing import List


class Solution:
    def minimumDifference(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        total = sum(sum(row) for row in grid)
        ans = float("inf")

        cur = 0
        for i in range(rows - 1):
            cur += sum(grid[i])
            ans = min(ans, abs(total - 2 * cur))

        cur = 0
        for j in range(cols - 1):
            col_sum = 0
            for i in range(rows):
                col_sum += grid[i][j]
            cur += col_sum
            ans = min(ans, abs(total - 2 * cur))

        return ans

func minimumDifference(grid [][]int) int {
	rows, cols := len(grid), len(grid[0])
	total := 0
	for i := 0; i < rows; i++ {
		for j := 0; j < cols; j++ {
			total += grid[i][j]
		}
	}

	ans := total
	cur := 0
	for i := 0; i < rows-1; i++ {
		rowSum := 0
		for j := 0; j < cols; j++ {
			rowSum += grid[i][j]
		}
		cur += rowSum
		ans = min(ans, abs(total-2*cur))
	}

	cur = 0
	for j := 0; j < cols-1; j++ {
		colSum := 0
		for i := 0; i < rows; i++ {
			colSum += grid[i][j]
		}
		cur += colSum
		ans = min(ans, abs(total-2*cur))
	}

	return ans
}

func abs(x int) int {
	if x < 0 {
		return -x
	}
	return x
}

func min(a, b int) int {
	if a < b {
		return a
	}
	return b
}
